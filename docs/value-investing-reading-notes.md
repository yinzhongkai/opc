# 《价值投资：从格雷厄姆到巴菲特（第 2 版）》阅读记录

2026-11-13 在 Codex 内置浏览器核对微信读书中文版版权页、目录和正文。页面标注出品日期为 2024-07-24，译者为林安霁、樊帅。正文通过页面渲染阅读，多个会员章节可打开。[阅读版本](https://weread.qq.com/web/reader/4f632770813ab90a0g01524b)

本轮核读范围覆盖第 1–11 章的下列正文节选及四个案例开篇。第 3、4、5、8、10 章的部分小节向下核读了多屏。全书逐页覆盖、各附录、脚注及案例表格未逐项核验。

| 正文范围 | 已核读的内容与提炼依据 |
| --- | --- |
| 第 1 章 | 价值投资定义。先对独立估计的价值与报价做比较，再考虑折价、规模和退出条件。书中的折价示例属于作者讨论的投资风格。 |
| 第 2 章 | 专业化、价值优势与机会筛选。窄领域积累能帮助识别暂时受损的业务，低估值分组的历史表现只提供初筛线索。 |
| 第 3 章 | 三要素估值、战略判断和成长预览。区分清算、再生产和无增长盈利，独立比较资产价值与盈利能力价值，再估成长。 |
| 第 4 章及案例一 | 清算、再生产与负债。哈德逊通用案例开篇将机场服务、房地产合营权益和母公司资产负债分别识别。 |
| 第 5 章及案例二 | 可持续可分配盈利、资本成本与股权价值转换。麦格纳国际案例开篇将行业恐慌与企业能否生存联系起来。 |
| 第 6 章 | 增长的资本代价及核心、邻近市场的扩张机会。增量投入回报与资本成本比较，验证优势能否随扩张复制。 |
| 第 7 章 | 经济特许权和竞争优势。验证进入难度、成本及需求优势，考虑受监管业务的回报约束。 |
| 第 8 章及案例三、四 | 现金分配、有机增长、再投资与优势衰减。WD-40 和英特尔案例开篇以历史时点复查原来的估值和预期回报。 |
| 第 9 章 | 间接线索、直接证据、管理层和催化剂。围绕最可能改变结论的变量做验证，用实际经营效率和资本配置评价管理。 |
| 第 10 章 | 风险度量、永久减损、分散、宏观、行为与组合管理。将个券研究的下行与全组合的共同敞口、现金需求及杠杆联动。 |
| 第 11 章与书末 | 浏览巴菲特、施洛斯父子、卡拉曼、鲁索的正文及译者后记节选。案例提供资本配置、资产折价和耐心资本等不同研究视角。 |

# 视频算法工程师

## 职责

- 依据已确认目标设计并实现视频分析、特征提取、候选事件检测和质量评估算法。
- 建立代表性样本、指标、参数版本、确定性和失败诊断机制，记录算法效果与性能证据。
- 维护算法输入输出、资源上限和批处理接口，向核心、媒体、构建和测试成员提供稳定契约。
- 评审影响视频分析正确性、可解释性、性能及模型许可的变更。

## 边界

- 不擅自改变产品效果口径、媒体时间语义或核心事件融合规则。
- 不以单一样例效果代替数据集评估，不在缺少证据时默认引入深度学习模型。
- 不决定媒体编解码、产品 UI、发布格式或第三方许可证结论。

## 主要产出

- 视频分析模块、算法接口与参数、样本和指标、自动化测试、效果与性能报告及开发交接资料。

# 发布工程师

## 职责

- 建立并维护可追溯的软件部署、打包、安装、升级、卸载和发布候选验证流程。
- 管理运行时依赖清单、软件物料清单、许可证材料、产物哈希和签名流程的工程边界。
- 在干净目标环境验证安装布局、启动、回滚、用户数据保留和诊断能力。
- 向构建、研发、测试和项目协调成员提供发布候选证据，评审影响分发与供应链的变更。

## 边界

- 不擅自决定产品发布范围、许可证法律结论、签名主体、渠道或上线时间。
- 不在未授权时接触或使用签名凭据，不以成功打包代替功能和产品验收。
- 不修改业务实现来掩盖依赖、安装或兼容问题，生产发布须有明确授权。

## 主要产出

- 发布基线、部署与安装脚本、SBOM 和许可证清单、签名工程流程、干净环境验证记录及发布交接资料。

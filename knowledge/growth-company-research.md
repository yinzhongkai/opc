# 成长企业研究

用于检验企业能否把需求、创新和组织能力，持续转成普通股每股现金与价值。根据菲利普·A.费舍《怎样选择成长股》所提供 EPUB 的三个部分及附录整理，[阅读与版本边界](../docs/growth-stocks-reading-notes.md)留档。本文是 OPC 的方法归纳，十五项问题不构成机械评分系统，也不保证投资结果。

## 把成长论点改成可证伪的问题

先明确研究主体、证券权利、分析时点和自己能够理解的业务范围。用一句话写出 `哪类客户需求 → 哪项产品或服务 → 如何销售与交付 → 需要多少资本 → 何时产生归属普通股的现金`。每一环分别列现有事实、管理层目标、研究假设和最可能失败的原因。

把存量业务、已经投入的新项目和尚未兑现的机会分开，避免把市场空间、订单、产品发布、收入和现金混为一谈。增长须进一步拆为量、价、产品和客户组合、地区、并购及汇率；企业规模、每股利益和投资者回报分别检验。

## 用十五项问题组织证据

以下是研究问题的独立改写；相关性依业务调整。不把“不知道”写成“通过”，也不让其他项目的高分抵消关键诚信或资金问题。

| 维度 | 要核查什么 | 可落地的证据和反证 |
| --- | --- | --- |
| 1. 现有市场潜力 | 需求还有多大空间，公司能否获利地满足它？ | 按客户、地区及用途测渗透、替换和增量需求，核对竞争、价格及现金回收；总市场规模不是可得收入。 |
| 2. 后续增长来源 | 当前产品成熟后，是否已有可信的新产品或市场路径？ | 核对产品组合、资源、试用和商业化里程碑，区分邻近扩张与无优势的多元化。 |
| 3. 研发成效 | 投入是否产生客户愿付费的成果？ | 按项目或代际追踪投入、人员协作、进度、失败、上市和利润；研发费用率不能单独衡量生产力。 |
| 4. 销售能力 | 能否找到、说服并持续服务客户？ | 查渠道、销售培训、获客成本、成交、续约与服务；产品优秀不自动带来收入。 |
| 5. 当前利润质量 | 相对同行及周期，利润率来自什么？ | 拆价格、成本、规模、会计和投入阶段；低利润可能是前置投资，也可能是产品无竞争力。 |
| 6. 未来利润维护 | 成本上升或竞争加剧时怎样维持经济性？ | 查工艺、效率、产品与客户组合，测试价格转嫁的时滞；短缺涨价不直接外推。 |
| 7. 员工关系 | 工作环境和激励是否支持人才与生产力？ | 比较同地区岗位流动、招聘、培训、安全与申诉，保留样本限制；不能用有无工会或单一评价直接判定。 |
| 8. 管理团队协作 | 是否按能力任用，能否共同作出决策？ | 核对职责、稳定性、跨部门执行和激励，区分合理分歧与长期破坏性冲突。 |
| 9. 梯队与授权 | 规模变大或关键人物离开时，组织能否运作？ | 查接班、实际授权、人才培养及异议机制；创始人声望、内部提拔或外聘均不能单独证明质量。 |
| 10. 成本与财务控制 | 能否知道产品、客户和项目真实的投入与收益？ | 对账分部、成本、预算偏差、营运资本和现金预警；公开信息看不到的内部精度须明确未知。 |
| 11. 行业独特因素 | 什么环节最影响该业务的相对优势？ | 按行业核对认证、服务、专利、渠道、租赁、信用等，不把一种行业的优势标准套到另一种行业。 |
| 12. 长期取舍 | 是否用合理的当前投入换取更大长期收益？ | 追踪具体项目和供应商客户关系，量化投入与回报；不能把每次盈利下降都解释成长期主义。 |
| 13. 融资与稀释 | 成长资金从哪里来，原股东实际得到多少？ | 按期编现金预算、融资与完全稀释情景，检查普通股、优先权、转换及分派限制；未来高价融资不能预设。 |
| 14. 坏消息披露 | 困难出现后，能否及时说明并纠偏？ | 对照原承诺、延误、失败、资源撤出与后续结果，核对是否变更指标或选择性披露。 |
| 15. 受托与诚信 | 掌权者是否合理对待普通股股东？ | 查关联交易、薪酬、股票授予、控制权及利益冲突，区分事实、解释和未证实指控；关键疑点未解时保持待核查。 |

## 多方取证与管理层提问

费舍的“闲聊”方法，是从不同利益位置交叉了解企业，不是传播市场传闻。先查公开财报、附注、公告、产品、会议纪要和竞争者资料，形成具体缺口；有实际访谈授权时，再针对缺口提问。研究方法本身不授权联系第三方、承诺保密、取得非公开资料或交易。

按客户、供应商、竞争者、现任或前员工、研究者及管理层列证据矩阵，标明每个来源能直接观察的事情、利益、时间和样本。多个来源来自同一原始叙述时合并计数。区分亲历、转述、预测和个人印象；前员工可能有特殊偏见，其他来源也一样需要核查，不能预设任一类别更诚实。

先了解业务与外部证据，再问管理层尚未解释的矛盾。提问从“具体发生什么、在哪个期间、影响多大、可用什么后续数据核对”出发，依据回答追问；不机械照读清单。保持对不利证据同样的调查深度，不把会面顺利、个人魅力或自信程度当作经营证据。

自拟调查条目：论点是客户因替换困难而续约；公开披露显示续约稳定，但客户可能只是尚在长约期。应分别查合同到期、主动续约、降价和使用强度，并观察多个客户群。未有真实访谈或对应样本时，不得编造客户评价和调查结果。关键缺口无法补齐时，保留观察、缩小结论或放弃研究。

## 连接研发、商业化与现金

为重要项目画出 `研发 → 试验/认证 → 量产/部署 → 销售 → 收款 → 后续维护` 的时间线。分别列成功条件、已发生证据、下一里程碑、追加资金、竞争反应和失败残值。实验室、试车和规模交付的成本及失败方式不同；技术性能更好也可能输给足够好而更便宜的方案。

研发、销售和生产需要协作。核查技术是否适合可服务的市场、现有渠道能否销售、产能和质量是否支持承诺。比较同口径多年研发产出，避免只数专利、发布次数或研发人数。失败项目应查终止纪律、资源是否及时释放及其他项目的机会成本。

用[股东盈利与会计质量分析](owner-earnings-analysis.md)核对利润与现金，用[价值投资与企业估值](value-investing.md)估增量投入回报。负自由现金流可能来自成长，也可能危及存活；先做现金预算，不能以看好远景代替偿付与再融资证据。留存盈余、分红、回购和融资都按每股经济后果比较。

## 用四个要素复核成长质量与价格

1. **经营能力**：生产或服务成本、销售、研发和财务控制是否相互支持，能否在低迷期继续运作。
2. **人员和组织**：能否维持授权、协作、接班、员工投入及适应变化的能力。
3. **业务经济性**：什么事情比对手做得更好，为什么优势不会迅速被侵蚀；使用[竞争优势与行业分析](competitive-advantage-and-industry-analysis.md)取证。
4. **价格与预期**：市场价格要求多快、多长、资本效率多高的成长，证据能否支持；区分公司、行业和整体市场的预期变化。

高 P/E 不自动等于高估，低 P/E 不自动等于低估；成长持续期、再投资、风险及最终估值均影响回报。即使预测期内盈余如期倍增，若之后增长消退、倍数下降，股价也可能不涨。不能为了保留高倍数，循环引用“公司优秀”作为证明。

自拟例：当前 EPS 为2、价格60，P/E 为30；五年后 EPS 假设为4，若退出倍数降至15，价格仍为60。忽略期间股息、费税和汇率时，资本年化回报为0%；若退出倍数仍为30，价格为120，资本年化约14.87%。两者都依赖假设，须把股息及融资、稀释、成本计回适用情景。正式估值仍用既有主模型，不能用增长率或预想的倍数上升代替估值。

## 持续复核与退出研究

买入前记录业务论点、证据、时间和失效条件，持有期间继续用外部和财务证据复核。市场价格上涨不能证明论点正确，价格下跌也不能证明只是暂时误解。重大坏消息先检查客户、竞争、治理、资金与执行是否改变，再决定它属于短期成本还是永久损失。

费舍强调尽早承认初始判断错误、基本质量恶化或更优机会出现，也警惕因为涨幅大而过早卖出。多尔西另强调极端估值及集中风险。综合使用时，逐情景比较继续持有、退出或替换的现金、风险、税费与机会成本，明确哪个假设造成结论变化；不能把任何一位作者的习惯写成自动交易指令。

原书三年守则是作者的经验性复核期限，五家、十家等分散建议也有历史背景。实际复核用可观察的经营里程碑和资金期限；集中度依据用户约束和组合共同敞口。基本面长期向好、规模大或历史上反弹过，都不保证本金安全或一定回到高点。

交付一份成长论点与十五项证据表、重点项目里程碑和现金需求、报价隐含成长及压力情景、最强反证和复核条件。向组合成员说明公司间的共同客户、技术、资金和估值风险；指数与基金还须核对产品权利、持仓权重、费用和流动性。资料缺失状态保留在结论中，不以固定持有年限、自动加仓或收益承诺填补。

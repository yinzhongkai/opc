# 研发工程师

## 职责

- 根据需求、架构和成员分工实现软件功能。
- 编写与变更相称的单元测试，修复缺陷并记录验证结果。
- 提供实现说明、调试证据和对接信息，配合相关成员完成联调。
- 前端、后端等具体方向由项目补充知识支持，任务归属以成员 scope 和负责人为准。

## 边界

- 不擅自改变产品范围和架构关键决策。
- 不批准自己的实现通过独立评审；生产发布须有相应任务授权。

## 主要产出

- 代码、单元测试、实现说明和开发交接。

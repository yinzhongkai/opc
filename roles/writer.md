# 作者

## 职责

- 根据读者、已确认大纲和资料撰写、修订内容。
- 保持叙述结构、术语和风格一致，为事实性主张保存来源。
- 依据事实核查与评审意见修订稿件，交接尚待验证的内容。

## 边界

- 不捏造来源、数据、案例或引语。
- 写作职责不包括自行批准最终出版，不把草稿观点视为项目正式决定。

## 主要产出

- 章节、稿件、来源注记、修订说明与编辑交接。

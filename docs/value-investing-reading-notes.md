## 四个主案例的复用检查

| 案例 | 复盘动作 |
| --- | --- |
| 哈德逊通用 | 先拆母公司资产、机场服务业务和地产合营权益。期权执行时，按出售收入和剩余权益计算，分别比较交易完成与维持现状。检查控股权变化能否让资产价值分配到股东。 |
| 麦格纳国际 | 用 2009 年可得资料先核对现金、低谷现金流和客户破产风险。将流动性受限的金融资产单列，再用再生产成本和正常盈利衡量核心业务。 |
| WD-40 | 分别冻结 1998、2000、2018 年的假设。检验顾客选购成本、货架和分销规模怎样延缓进入，重新估计线上渠道削弱优势后的回报。分列当时估计和后来实现。 |
| 英特尔 | 用研发和客户关系投入调整再生产成本。按存储、桌面和服务器等市场核实竞争结构，再分别用 1999、2003、2018 年的现金分配、资本密集度、有机增速及收购回报估价。用低功耗市场检验优势的覆盖边界。 |

文件于 2026-09-28 从原 `projects/book-yocto/workspace/` 迁回 OPC，迁移依据见 [D-012](../../DECISIONS.md)。旧任务中的 `workspace/<file>` 对应本目录同名文件；原始版本与完整修改历史仍可从 OPC 归档标签 `archive/2026-09-28/book-yocto` 追溯。

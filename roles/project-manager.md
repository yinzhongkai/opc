# 项目经理

## 职责

- 依据已确认目标组织里程碑、任务负责人、依赖和风险。
- 根据成员在 TASKS.md 中更新的实际进展、成果和阻塞汇总 STATUS.md，并处理协调请求。
- 维护任务计划：新增或移除任务，调整负责人、依赖、优先级、范围和完成条件；成员可直接更新自己的任务进展，无需项目经理逐条转录。
- 把专业问题交给对应成员，将成员与知识缺口交给组织管理员。
- 运用项目补充的领域知识理解依赖、估算与风险，具体专业执行仍由对应成员负责。

## 边界

- 不以进度协调替代专业结论，也不擅自改变已确认目标和资源约束。
- 不作为自己直接制作产物的独立评审人。

## 主要产出

- 任务计划、项目状态、风险记录、交接与阶段总结。

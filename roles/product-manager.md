# 产品经理

## 职责

- 澄清目标用户、问题、使用场景和非目标。
- 定义范围、优先级和可验证验收标准，维护需求产物。
- 向架构、研发和测试成员交接已确认需求，记录未决定事项。
- 评审方案、实现说明和验收资料，检查其是否符合目标用户、已确认范围和验收标准。

## 边界

- 不擅自决定技术实现；建议中的范围变化需要进入项目决策流程。
- 不代替测试成员宣告实现已经符合验收标准。

## 主要产出

- 需求说明、用户场景、优先级、验收标准、需求交接资料和产品评审意见。

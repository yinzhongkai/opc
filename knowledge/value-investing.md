# 价值投资与企业估值

用于筛选和研究普通股。先独立估计资产价值和无增长时的盈利能力价值，再判断成长需要多少资本、超额回报能维持多久。财务数据、报价和证券权利按[证券分析](securities-analysis.md)核对。方法参考格林沃尔德等《价值投资：从格雷厄姆到巴菲特（第 2 版）》第 1–8 章及案例，算例均为自拟。

## 筛选和确定研究问题

1. 先限定能解释客户需求、成本结构、竞争格局和资本需求的业务范围。低估值、分拆、重组、周期低谷或受限持有人的卖出可以形成候选。记录报价日期、可能的卖出动因和自己能核实的判断差异，检查便宜是否反映结构性衰退或持续耗资。
2. 先问哪项证据最可能改变价值判断。资产型机会优先核实权属、变现、偿付和处置时点。盈利型机会优先核实正常利润、维护投入和现金回收。成长型机会优先核实进入壁垒、新项目回报和可扩张范围。机构持仓及同行观点可用于发现线索，留意披露滞后，关键假设用可核对的证据独立验证。
3. 将自身历史估值分位和同口径同业比较用于筛选。剔除周期利润高点、会计口径变化和一次性股息对指标的扭曲。研究分拆、指数剔除或评级下降时，查公告日期、真实持有人约束、交易容量和成本。检验一篮子规则时保留当时可投资的退市样本，使用当时已披露的数据与可成交假设，比较扣费后的基准回报和下行。

## 选择估值方法

- 现金流金额与支付日期相对可核查的证券，用 `NPV = Σ[CF_t ÷ (1 + r)^t] − 初始投入` 测算持有价值，分别列完成、延期和失败情景。对依赖遥远终值的企业，披露终值现值占比，联动改变折现率和长期增长率，并用资产或无增长盈利校验。
- 评估股权时先区分清算、持续经营和有证据支撑的获利成长。周期性重资产企业重点核查进入成本与持续经营需求，成熟轻资产业务重点核查正常盈利及客户、技术等无形资产。说明选用基线和替代估值各自的不确定性。多业务公司允许各分部使用不同方法，再统一为归属普通股的口径。

## 资产价值

- **清算口径。** 按资产权属、收款能力、买家、用途和时间估计可变现额。扣除未入账义务、税费、处置成本和等待期间的现金消耗，按受偿顺序算普通股可得净额，再折现。对控股公司按分部、合营权益和母公司净资产分别估计，核对实际可分配比例和资金限制。
- **持续经营口径。** 以具备竞争力的进入者按当前技术复制同等产能和客户服务能力所需的净投入估算再生产成本。将营运资本调整到正常周转水平。设备按等效能力核价，调整现有资产的成本劣势、寿命和残值差异。能用证据估计的渠道、客户获取、培训或必要研发成本可以计入。核对费用已否反映在其他资产项目中，将多余资产和融资负债按统一口径单列。
- 保留每项的账面额、调整后区间、依据、估计误差和实际可兑现条件。持续经营能力不明时同时列清算情景。再生产成本衡量进入者要花多少钱，兑现净额另取决于资产可售性、控制权和处置计划。

| 资产项目 | 可执行核查 |
| --- | --- |
| 现金、应收、存货 | 检查受限现金和资金归属，应收按账龄、客户信用与已知收款分组，存货按年龄、品类及实际出货折价。区分立即出售和有序处置。 |
| 厂房设备、地产 | 清算用可实现成交与出售周期。再生产比较新建、扩建和购买等效资产的全寿命成本，纳入施工、调试、利用率、运营费用和残值。 |
| 技术、客户和组织 | 以今天重建所需的费用及时间估计。可把仍有效的历年研发按技术寿命加权，客户关系用有效获客成本乘需要建立的活跃关系数量核查。账面商誉独立剔除后再辨认有效资产。以可比交易交叉检验时，扣除可识别资产并核实控制权溢价、协同及成长预期。 |
| 债务和其他索取权 | 核对担保、租赁、养老金、诉讼或修复义务、少数股东和优先权益。经营资产与经营性流动负债若已按净额估计，转股权价值时保留该净额。 |

分部加总时，单列总部成本、母公司债务、交易税费及受限资金。若出售部分股权，用出售净收入加交易后保留股份的价值。合营项目按其价值是否已经归属母公司决定是否再乘持股比例。将交易完成、延期及维持现状各做一列，注明谁能推动、时间成本和决策进展。

## 盈利能力价值（EPV）

1. 估当前业务规模下可持续的经营收入和营业利润率。对周期企业使用正常产量、价格和利润率，结合可比期间核查高低点。历史口径发生结构性变化时，用有依据的近期经营能力重建。按[盈利正常化](securities-analysis.md#重建盈利和现金流)处理一次性收益和持续性成本。
2. 估计无增长时的企业可分配现金流。用正常化营业利润乘 `(1 − 正常化经营税率)`，加回所含折旧摊销，再扣除维持性资本开支和净经营营运资本的增加额。在收入、价格和周转率均稳定的无增长假设下，营运资本的年净增加额通常为零。若估值日还需补足正常营运资本，将这笔投入单列。对研发、获客和培训，维持现有竞争地位的支出留在经营成本中。仅在能核实支出用于增量业务、停掉后现有业务仍可维持时，按税后口径调整增长投入，并在成长情景计回相关投入。用跨期经营现金流、产能和收款记录交叉核对。
3. 对可持续且可视为无增长永续的业务，用 `正常化无增长企业可分配现金流 ÷ WACC` 估算经营资产 EPV。现金流与资本成本的币种和通胀口径要一致。加上未计入经营现金流且可分配的非经营资产，扣除融资债务、其他在先权益及少数股东权益，再除以同口径稀释股数。现金流明显不稳定或资产寿命有限时，按期限估现金流与剩余价值。对资本约束主导的金融企业采用可分配股东现金流和股权要求回报率，核查监管资本和分派限制。

估维持性开支时，用低增长时期的总开支与 `当前总开支 − 可比增量收入 × 边际产能投入强度` 交叉验证。检查设备更新计划、延后检修、价格变化、并购取得的产能和技术换代。用正常化现金税核对折旧调整和可兑现税盾。估 WACC 时用可持续资本结构、同类债务融资成本及股权机会成本区间，并对照压力现金预算核实资本结构可维持性。

### 用两种估值互相核对

| 经营资产估值关系 | 下一项核查 |
| --- | --- |
| EPV 低于再生产成本 | 检查资产陈旧、行业收缩、利润处在周期低谷或管理效率低下。检验能否变现、退出或改善经营，并计入时间和成本。 |
| EPV 接近再生产成本 | 检查进入和退出是否会把回报拉回资本成本。对成长溢价要求新增资本回报的独立证据。 |
| EPV 高于再生产成本 | 检查再生产成本是否遗漏关键资产，盈利是否含周期峰值或暂时供给短缺。确认差额来自哪些可持续壁垒，再估这些壁垒的衰减。 |

在同一业务范围和资本结构口径下比较。资产价值和 EPV 都覆盖现有业务，整体估值选用适用的基线，并单列有证据的增量价值。

## 成长、竞争优势与报价隐含条件

1. 按产品、地区和客户群界定共享成本及同一竞争规则覆盖的市场。将份额稳定性、按重置资本估计的超额回报及实际进入案例交叉核对。用复购、留存、替换成本验证客户锁定，用费用结构验证规模优势，查明专利或许可到期、替代技术及客户自研会怎样改变这些条件。
2. 模拟最有能力进入的对手。用 `（年固定运营成本 + 年资本费用）÷（单位贡献率 × 市场销售额）` 估计需覆盖资本成本的最低市场份额，单位贡献率取每单位销售收入扣除变动成本后的比例，资本费用与贡献使用同一税务口径。投入、单价或成本随规模变动时分档建模。将需要的份额和资金耐力与客户流失、认证周期、产品换代和渠道可得性比较。
3. 用同店、存量客户、成熟产品、行业容量及价格估有机增长，再算额外营运资本、产能与获客支出。对主动投资，分别检查核心市场、可复用优势的邻近市场、竞争开放的新市场及已有强势在位者的新市场。按投产后的增量税后经营利润除以对应增量投入资本估回报，匹配投入和回报时点。增长创造价值的条件是增量回报持续高于对应资本成本。行业收缩时同步测试固定成本难以削减对盈利的影响。
4. 用 `报价对应企业价值 − 经营资产 EPV` 测算市场为改善与成长支付的价差。反推需要的利润率、投入回报及优势持续期，再与上述行业证据核对。采用有限期情景时，用增量税后经营现金流扣除相应投入，折现估计该部分价值。

### 估计成长股回报

对核心业务有持续优势、盈利和资本配置可合理估计的企业，用同口径的回报拆解比较报价和资本成本。

| 输入 | 估计方法 |
| --- | --- |
| `M`，市场对价 | 企业口径使用核心经营企业价值，先移除可分配的非经营资产。股权口径用对应股权对价和股权要求回报率。 |
| `E`，正常化现金盈利 | 使用扣除维持投入后的核心现金创造额。股权口径进一步核对利息和维持资本结构所需的债务现金流。 |
| `D`，可持续现金分配 | 股权口径为股息加净回购，核实增发、股权薪酬及股数变动。企业口径还包含归债权人的税后利息及净偿还，扣除新增融资。按多期总分配与总盈利核对，检验压力下是否靠消耗现金或加杠杆维持。 |
| `g` 与 `I_org`，有机价值增长与所需投入 | 用核心业务可持续盈利增速近似 `g`，要求利润率、资本强度和价值与盈利的比例具有稳定依据。用增量收入乘边际投入强度估 `I_org`，加计尚未在 `E` 扣除的支出。 |
| `I_active` 与 `v`，主动再投资与价值创造因子 | 在现金预算中以 `E − D − I_org` 校验自筹资金。缺口需重估分配、增长或融资。`v = 项目未来净现金流现值 ÷ 投入`，在新增现金长期稳定且即时达产的简化情形，约为同口径增量现金回报率除以资本成本。按经营改善、扩张、并购或闲置资金分别估计。 |

以 `r_b = D/M + g + I_active × v/M` 做初筛，有机项此时假设内在价值等于市场对价。若另有可靠的同口径核心价值 `V`，用 `g × V/M` 计算有机增长对当前报价的回报贡献。分配中已含净回购时，有机项以业务总量估增长，避免将股数减少计入两次。`v` 表示每单位投资带来的总价值，比较该资金若直接分配的价值时用 `v − 1`。

将技术替代、渠道变化或进入壁垒衰减反映在增长、利润率、持续期或单列损失中，记录每个冲击进入模型的位置。若假设独立且恒定的年度优势消失概率，可由半衰期 `H` 得 `p = 1 − 0.5^(1/H)`。部分侵蚀时，以 `p × 受损比例 × 受影响价值 ÷ M` 近似当期回报扣减。概率和损失幅度应做区间检验。采用逐年衰减或有限期现金流时，相关损失已反映在各期现金流。用衰减调整后的回报和同口径资本成本比较，报告超出或低于要求回报的百分点。

附录的稳态交叉检验采用 `V = D_next ÷ (k − G)`、`R = D_next/M + G × V/M`。`D_next` 是下一期分配，`G` 是该分配口径下的持续增长率，`k` 是匹配的资本成本。只在分配和增长假设一致且 `G < k` 时采用，检查 `k − G` 缩小后的敏感性。逐项回报拆解与稳态交叉检验分别使用，避免把主动投资既计作独立贡献又计进永续增长。

例如以核心股权口径估计 `E = 20`、`D = 10`、`I_org = 4`、`v = 0.75`、`g = 4%`、`M = 180`。`I_active = 6`，现金分配收益约 5.56%，主动再投资贡献 2.50%，初筛回报约 12.06%。若独立估计 `V = 150`，有机贡献约 3.33%。若年度冲击概率取 2%，冲击时受损比例取 50% 且影响整个 `V`，回报扣减约 0.83 个百分点，调整后为约 10.56%。要求回报若为 11%，该假设下报价未达到要求。逐年现金流和压力估值仍用于核查等待期及损失。

若用户给出要求回报 `r_min > 0`，可用同一模型反推对应的价格。令 `L` 为年度价值损失的金额估计，若各金额在测试价格区间可近似固定，则 `M_max = (D + g × V + I_active × v − L) ÷ r_min`。以上例输入，`M_max = (10 + 6 + 4.5 − 1.5) ÷ 11% ≈ 172.73`。这是回报门槛对应的核心股权对价。先核实不同价格是否改变回购、融资或分配假设，再换算为同口径每股价格。另按保守价值和所需折价计算安全边际价格，分别说明两项门槛的依据。

## 安全边际和可复算示例

假设某企业正常化营业利润 40，经营税率 25%，折旧摊销 8，维持性资本开支 12，营运资本净变动为零。无增长企业现金流为 `40 × 75% + 8 − 12 = 26`。WACC 取 10%，经营资产 EPV 为 260。加可分配非经营资产 30、扣债务 70，得到股权价值 220，10 股对应每股 22。若经营资产再生产成本为 200，则 60 的差额需要壁垒或估计误差解释。

报价为每股 28 时，对应企业价值为 `28 × 10 + 70 − 30 = 320`，高于无增长 EPV 60。若一项新增投资 50 可长期产生年度增量税后现金 8，并假设即时投入、下一期起稳定实现且现金已扣除维持投入，10% 折现下该项目净现值为 `8 ÷ 10% − 50 = 30`。该项目可解释 60 价差的一半。若资本成本升到 12%，原有业务的每股 EPV 降至约 17.67。对每股 22 的保守价值，采用 20% 安全边际的示例价格为 `22 × (1 − 20%) = 17.60`。所需折价按估计误差、兑现难度和永久减损情景确定。

交付记录分析时点、资产估值表、无增长现金流及资本成本、报价隐含成长、压力价值、关键反证和触发复核的条件。若依赖出售、管理改善或回购兑现，注明有权推动的人、预计时点、所需资金和未兑现情景。

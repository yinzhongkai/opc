# 前端开发

在实现网页页面、组件和交互时，处理界面状态、数据请求、可访问性与响应式布局，并验证用户可观察行为。

## 界面与数据状态

划分服务端数据、表单输入和临时界面状态，明确唯一来源。为请求准备加载、空数据、失败和成功状态；处理连续输入或请求返回顺序变化，避免旧结果覆盖新状态。

表单反馈同时覆盖输入提示、校验错误和提交结果；防止重复提交时保留必要的用户反馈。前端校验改善体验，不能替代服务端的数据约束。

## 实现方法

沿用项目组件与样式约定，按职责拆分可复用部分。使用语义化元素、可识别标签、键盘操作与合理焦点顺序；结合目标设备验证布局，不能只根据某一窗口宽度判断完成。

以接口契约实现数据映射与错误展示；使用模拟数据时明确标识，联调后验证真实请求与边界值。框架、版本和构建方式由项目约束确定，不在共享知识文档中固定 React 或 Vue。

## 验证重点

检查主要用户路径、失败后的恢复、空列表、长文本与重复操作。组件测试关注输入与可观察结果；页面运行检查关注交互、布局和网络行为。

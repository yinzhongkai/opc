# 项目公共指令

每个会话代表一个项目成员，成员对应一个共享岗位，岗位规定职责与基础知识。项目可以在 TEAM.yaml 的 roleKnowledge 中为岗位补充领域知识，成员分工保存在 scope 中。

用户声明身份后，读取根目录 AGENTS.md 和 SESSION_PROTOCOL.md：

1. 根据项目 TEAM.yaml 唯一解析 active 成员与岗位。
2. 读取 roles/<role-id>.md 的职责与 knowledge 基础列表。
3. 读取本项目 roleKnowledge 中对应岗位的补充列表；缺省使用空列表。基础列表在前，补充在后，按首次出现顺序合并去重。
4. 完整读取每个有效 ID 对应的 knowledge/<id>.md，再读取项目背景、任务、决定和交接。
5. 汇报实际读取文件、基础与补充知识、岗位职责、成员分工和任务。

同项目同岗位的成员使用相同知识集合，scope 区分实际工作。知识不能覆盖职责、移除基础知识或授予额外权限。

成员直接更新 TASKS.md 中自己任务的状态、进展、产物链接和阻塞；任务计划调整由项目经理负责。普通进展无需重复写 HANDOFFS.md，需要其他成员行动或接手时才建立交接。详细边界以 SESSION_PROTOCOL.md 为准。

缺少必需资料、字段无效或身份不匹配时说明具体问题，不声称初始化完成。新任务前刷新成员记录、项目岗位补充知识和相关资料。需要共享的信息写回项目文件；无法写回时提供建议路径与内容，并明确尚未保存。

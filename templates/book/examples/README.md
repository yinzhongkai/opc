# 配套示例索引

> 技术书可选模板；没有实际工程时保持空表，不用示意仓库或占位提交号冒充交付。

每个示例关联其主成果、负责人和任务；代码可存于本目录或项目约定的源码位置。书稿节选只作展示，完整可执行材料以索引所指版本为准。

| 示例标识 | 主成果与任务 | 负责人 | 实际工程路径或可访问仓库 | 提交、标签或可复核版本 | 使用章节标识与正文版本 | 准备与运行说明 | 验证记录位置 |
|---|---|---|---|---|---|---|---|

暂无示例。示例 README 应说明依赖、准备、执行位置、构建或运行命令、预期及已知限制；执行结果引用章节记录，不维护第二份通过清单。标签只有实际存在且能解析时才能登记。

示例演进需记录影响章节，不能更新同一文件后默认旧章节依然可复现。测试代码与被测实现分开定位；涉及设备的操作按实际权限与安全条件执行。

# 股东盈利与会计质量分析

用于把报告盈利转为有经济解释、可核查的经营与股东现金创造能力。主要依据《巴菲特致股东的信：投资者和公司高管教程（原书第4版）》第6至9章，并结合第1章披露方法；全书覆盖见[阅读记录](../docs/buffett-shareholder-letters-reading-notes.md)。下列计算桥接和算例为 OPC 整理，不是原书逐字公式。

## 固定分析口径

记录报表主体、期间、币种、股数、会计准则及附注位置，区分母公司、合并集团、经营分部和持有投资。会计账面值、市场价格、内在价值分别列出。财报是调整的起点，所有调整保留原数、金额、税效应、现金时点和业务依据。

原书包含历史美国会计与税制案例。实际任务重新核验适用准则、披露和税务事实；书中的商誉摊销年限、投资会计持股比例或税率不能直接作为当期规则。本文不代替审计或税务认定。

## 建立股东盈利桥接表

对适合该方法的非金融企业，可从同口径的正常化税后普通股利润出发：

`股东盈利估计 = 正常化税后利润 + 可适当加回的非现金费用 − 维持竞争地位和业务规模所需资本开支 − 同一假设下新增经营营运资本`

1. 按[证券分析](securities-analysis.md#重建盈利和现金流)核查一次性项目、周期、税负、费用资本化及反复发生的重组支出。先确定哪些成本反映持续的经济消耗，再决定是否调整。
2. 将折旧、摊销和其他非现金项分开，区分购买价分摊造成的报表变化与实际资产消耗。经济成本未消失的项目不能仅因“非现金”而永久加回。股份支付属于经济成本；保留费用或采用有依据的替代成本、稀释处理时，说明选择并用股数桥核查，避免遗漏或重复计算同一成本。
3. 估计维持产量、服务能力及竞争地位所需的更新投入。使用设备寿命、更新计划、多年开支、产能和技术变化交叉验证，披露区间及误差。折旧金额是线索，不能直接当作维持开支；延后维修带来的短期现金改善需要恢复正常。
4. 将营运资本投入与所用经营假设对齐。增长、通胀和周转恶化可能增加资金需求；一次性释放不能直接永续化。已在起算现金流中扣除的同一占款，不再重复扣除。
5. 维持投入与成长投入分列。股东盈利用于观察当前业务的现金能力；估计成长价值时须扣回支持该成长的投入。已承诺的成长支出、债务到期、分派限制及其他义务仍影响实际可分配现金。

自拟例：正常化税后利润 100，合适的非现金加回 30，维持开支 40，新增营运资本 10，股东盈利为 `100 + 30 − 40 − 10 = 80`。维持开支若在 30 至 50 之间，对应估计为 90 至 70。若另有已承诺成长支出 25，扣除该项后剩余为 55，其他融资和分派限制另查。将 130 当作可分配现金会漏掉维持投入与占款。

这种估计不等于法定可分配利润、当期银行存款或承诺股息。金融企业、资本监管或特殊融资结构主导的主体，应另核查资本补充与可分派股东现金；不能直接套用普通工业企业公式。

对通胀、技术更替和竞争性设备升级，分别估维持当前实物能力和维持竞争地位的投入。成本节约若很快被降价抵消，不能把开支全部视为高回报成长。原书对轻资本经济商誉的偏好提供比较思路，仍须验证具体业务的定价、客户留存及更新需求。

## 与现金流和收购会计交叉核对

| 调整问题 | 核查动作 |
| --- | --- |
| 利润增加，现金未改善 | 桥接应收、存货、应付、资本化、准备金和已实现损益，核对收款及付款时点。区分正常季节性、经营变化和无法解释的偏差。 |
| EBITDA 或“现金盈利”很高 | 明确指标排除的利息、现金税、维持投入及营运资本，再与实际现金预算核对。它可以作比较指标，不能独立证明可分配现金或偿债能力。 |
| 收购后报告利润下降 | 逐项解释购买价分摊、额外折旧摊销、税项和融资变化。判断哪些改变实际现金，哪些只是计量变化；经济状况相同不能仅因列报不同得到不同的价值。 |
| 会计调整后利润很好 | 用多年现金回收、实际维护及同行数据反向检验。反复重组、乐观养老金估计或选择性实现收益是进一步核查的线索，不自动成为可加回项目。 |

从经营现金流起算时，先核对利息、税和租赁等分类，再替换异常营运资本，扣除适用投入。与利润桥接表对账，列出差异。企业口径的现金流使用匹配的资本成本并调节到股权；普通股口径使用对应的股权回报要求，避免利息、债务和现金重复处理。具体估值按[价值投资与企业估值](value-investing.md)执行。

## 检查跨期会计选择

| 对象 | 建立的底稿与判断 |
| --- | --- |
| 重组与收购准备 | 按项目滚动核对 `期初余额 + 本期计提 − 现金使用 ± 其他变动 − 转回 = 期末余额`；注明币种、非现金使用和分类变化。追踪收购时的大额计提是否通过后续少计费用或释放准备抬高盈利，频繁发生的重组计入正常成本。 |
| 股份支付 | 查授予、归属、行权、失效、回购及净股数变化。成本确认与期权经济价值分开核查；采用替代现金成本或稀释模型时说明完整处理路径，避免既漏掉员工报酬又把同一成本扣两次。 |
| 退休福利 | 同列义务、计划资产、缺口、服务成本、现金缴款及实际投资回报；拆开预期回报、折现率、寿命和医疗费用假设对当期利润与负担的影响。高股票占比与乐观回报假设均需压力测试，历史资产回报不能直接证明未来可实现。 |
| 已实现与未实现收益 | 记录出售与持有如何影响报表利润、现金税和剩余资产。选择实现盈利可以改变报告时点，不能据此认定底层经济价值增加。按当前准则核验分类，原书历史列报方式只作背景。 |
| 分部与合并 | 核查范围变化、内部抵销、总部费用和分部间转移；按实际经营特征解释资本及现金，不让合并利润掩盖分部持续耗资或现金受限。 |

异常只是取证起点。先保留原始列报，再列管理层解释、替代解释、可验证的后续现金和反证。第7章 A 的虚构钢铁公司会计报告是讽刺案例，不能当作真实公司财务资料或推荐处理方法。

## 穿透所持投资的盈利

对集团或投资持有人，可以编制独立于法定报表的研究指标：

`穿透盈利 = 本体正常化利润（剔除本次穿透投资已计入的收益） + 各被投企业可持续税后利润按经济权益归属的份额 − 额外税费`

先列出投资清单、经济持股比例、报表已确认的分红、权益法收益、公允价值或处置损益。已合并或按份额确认的同一利润只计一次；多层持有按归属路径核对，不把直接与间接权益重复相加。额外税费按假设的分派或退出方式测算，不能把原书历史税率搬入模型。

穿透盈利反映经济利益，不代表被投企业已交付现金。单列实际收到的股息、被投企业维持及成长投入、留存回报、分派限制、控股方决策权和潜在稀释。未分配利润能否创造价值，使用[治理与资本配置](owner-oriented-governance.md)的方法验证。

## 商誉、税与每股价值

- 会计商誉来自交易计量，经济商誉来自可持续的超额经营回报。以客户行为、定价、资本需求和竞争证据验证后者。账面商誉存在或未减值，不能证明护城河；剔除摊销也不能免除对技术、客户和组织更新成本的检查。收购价的回报检验仍应计入实际支付的全部经济对价。
- 按投资者实际身份比较税后现金。持续持有、分红、出售及再投资可能具有不同的纳税时点，分别列成本基础、当期现金税、递延负担和最终退出净额。递延纳税不是免税；税务因素与经营价值、风险及替代机会共同比较。
- 将总盈利增长、再投资、净发行或回购造成的股数变化分开。报告实际与同口径稀释股数、每股盈利和每股价值；不能用回购导致的 EPS 增长替代经营改善。

将经济商誉与有限寿命的客户关系、技术和许可分开。前者能否持续或增长要用超额回报证据验证；后者需要更新投入与经济消耗估计。比较有形资本经营效率时可以单列购买商誉，评价收购回报时仍保留全额历史成本，分别标明分母用途。

递延税按来源、账税基础、预计反转时间、适用税率和可抵扣条件分组。账面负债、按假设估计的经济现值及未来现金税分别列示；既不能一律按立即支付处理，也不能当作可随意分配的权益。折现现金流已含税款时，估值调整避免再扣同一负担。对递延税资产核查可利用利润及失效条件。

公司名义缴税与经济负担分开分析：竞争、定价和监管可能让部分税负由客户或其他方承担，不能把一个行业的结论泛化。投资者层面另列分红、出售、汇率、通胀和最终退出后的购买力；递延税优势需与经营恶化、资金需求及替代机会共同检验。

## 交付

保留报表到正常化利润、利润到股东盈利、现金流交叉验证及股数的四张桥接表；使用穿透方法时另附投资归属和分派表，有重大准备金、养老金或递延税时附对应滚动表。每项估计给出处、期间、税效应、区间及反证，注明尚未解释的差额和触发复核的变化。资料不足时给条件判断，不能用一个精确数字遮盖维持开支或权利的不确定性。

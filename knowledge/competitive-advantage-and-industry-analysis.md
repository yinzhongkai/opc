# 竞争优势与行业分析

用于把行业经营方式、客户选择和竞争者反应，转成可验证的现金流与优势持续期假设。主要根据帕特·多尔西《股市真规则（畅销版）》第3、6、13至26章整理，结合全书财务与估值检查；[版本与完整阅读记录](../docs/stock-investing-rules-reading-notes.md)留档。以下表格及算例为 OPC 归纳，不是原书评级或当期行业建议。

## 从赚钱方式开始

先写清谁使用、谁选择、谁付款、为何购买、如何收费和何时收款。按产品、地区、客户群与竞争规则界定市场；多业务公司分开研究，再处理共享成本和内部交易。行业收入增长、社会效益和股东回报是三个问题。

用同口径的多年利润、资本回报、现金回收和份额变化发现线索。区分周期、暂时短缺、垄断许可、收购和会计变化，不以某一年的高利润或公司规模直接判定护城河。高 ROE 先拆利润率、资产周转与财务杠杆；净资产很小、回购或减值可能改变分母。

对适用的非金融企业，比较正常化税后经营利润与相匹配的平均经营投入资本，说明现金、商誉和非付息经营负债的处理。经营效率可以另列不含购买商誉的口径，但收购回报仍计实际全部对价；金融企业采用资本约束适用的口径。增量项目的投入、达产时间和收益另测，不把历史高回报自动外推到新增投资。

## 为每项优势建立证据和反证

| 优势来源 | 需要解释的机制及证据 | 可能使其失效的变化 |
| --- | --- | --- |
| 产品差异与品牌 | 客户愿意为质量、可靠性或体验支付溢价；比较净价、复购、获客及持续广告研发成本。知名度只是线索。 | 促销依赖、同质化、客户偏好转变、维护品牌的成本超过溢价。 |
| 成本与规模 | 查采购、制造、网络密度、渠道或固定成本摊薄带来的单位成本优势；比较同质量和同服务下的成本、利用率及全寿命投入。 | 规模不经济、过剩产能、更便宜的新工艺，或资本大量进入消除原有门槛。 |
| 转换成本 | 区分迁移费用、培训、认证、流程中断、数据及互操作性；以实际续约、流失原因和替换行为核查。 | 新方案的收益超过迁移成本、开放标准、客户多供应商策略或自研。 |
| 网络效应 | 解释新增参与者如何提高其他参与者所得价值，明确同侧、跨侧和适用市场；查活跃、参与质量与变现成本。 | 多平台并用、拥挤和低质量、参与者转移、补贴成本侵蚀收益。用户多本身不能证明网络效应。 |
| 专利、许可及其他进入限制 | 核对权利主体、覆盖范围、到期、替代路径、维权成本和适用辖区，说明限制如何转成可保留的利润。 | 专利或独占到期、替代产品、政策及费率变化、诉讼或客户议价。 |

原书强调技术领先常被模仿，不能据此省略商业取证。技术若与持续研发、工艺积累、认证、渠道和客户使用习惯结合，可以形成优势假设，仍需分别验证。低价、优秀管理、热销产品或高市场份额，也都不是单独充分的护城河证据。

每项结论至少保留 `市场边界 → 客户所得 → 成本或收入效果 → 必需投入 → 竞争者应对 → 反证 → 失效指标`。多篇材料转述同一管理层说法，只算一条来源。无法取得独立证据时，标明假设和信息缺口。

## 把深度、期限和增长资金连起来

优势深度指超额经营回报的幅度，持续期指这种回报能保持多久。分别测试竞争进入、价格下降、替换周期和维护投入，不用行业平均高增长代替公司持续期。解释进入者为何现在不进入，以及什么变化会让进入划算。

拆开价格、销量、新产品、客户或门店、地区、并购和汇率带来的增长。先核对定义和加总关系；新店成熟、提价、收购及低基数均可能抬高表面增速。对每项增长同时列营运资本、研发、获客、设备和融资需求。经营现金流减全部资本支出，与扣除维持投入的股东盈利回答不同问题，按[股东盈利与会计质量分析](owner-earnings-analysis.md)桥接。

自拟例：某项目投入经营资本100，达产后每年增加税后经营利润15，粗略增量回报为15%；还须检验达产等待、后续更新、营运资本和相应资本成本。若另需20营运资本而原来漏计，分母变为120，回报降为12.5%。不能以15%的旧结果支持包含额外投入的增长。

## 按经营方式选择行业指标

下面是调查入口；指标不是统一买入阈值。按报告期、辖区和具体业务重新核验财报定义与适用规则。

| 业务 | 优先观察 | 重点反证与误用 |
| --- | --- | --- |
| 药品、生物技术与器械 | 需求与支付方、产品和专利集中、研发阶段、临床或认证证据、产能、商业化现金及资金跑道。 | 技术成功不等于商业成功；旧书研发成本、审批时间及成功率不能充当当期概率。器械培训和转换成本也须实证。 |
| 医疗保险与管理服务 | 承保风险承担者、收费服务与自担风险业务、医疗支出、费率及合同结构。 | 业务混合变化扭曲赔付指标；定价和政策风险不能用规模抵消。 |
| 餐饮与零售 | 单店盈利、同店口径与成熟店群、新开与关闭、回本期、存货和收付款周期、租赁义务。 | 新店成熟掩盖老店衰退；延期付供应商不是可永久重复的增长；租赁核对已入账负债和付款，避免再加一遍。 |
| 商务服务 | 区分技术、人力和实体资产驱动，核对续约、合同期限、客户集中、人力利用率及固定网络成本。 | 合同金额不等于已确认收入或已收现金；轻资产叙事不能遮住人力、数据及系统维护投入。 |
| 银行 | 存款稳定与成本、资产和负债重定价、信用组合、逾期与核销、拨备、资本和流动性。 | ROE 可能来自杠杆或拨备不足；存款保险与规模不能证明无风险；利率变化同时影响资产、融资、信用及估值。 |
| 资产管理与托管 | 将资产规模变化拆成市场涨跌、净申赎、并购与汇率；核对费率、产品客户结构、留存及技术运营成本。 | 规模增长未必带来同速收入；托管资产和受托管理资产含义不同，客户承担投资损失不等于管理人没有经营和责任风险。 |
| 寿险与财险 | 区分承保与投资、产品保证、资产负债期限、准备金变化、灾害或长尾风险、再保险及资本。 | 高保费增长可能低估风险；综合成本率核对分子分母定义，不能把浮存金当股东可自由分配的现金。 |
| 软件 | 分清许可、订阅、用量、实施与维护；核对续约、收入确认、应收、合同负债及客户使用。 | 递延收入变化可能来自账期、合同期限或组合；不能机械套旧书许可模式，亦不能假定云服务或 AI 推理边际成本为零。 |
| 硬件及半导体 | 产品组合、量价、渠道与终端存货、设计认证、良率、利用率、供应承诺、研发与更新资本。 | 需求前置、重复下单和渠道积压；技术优势需连接生态、成本和客户行为。设计、代工及设备商不能用同一资产强度。 |
| 媒体 | 拆广告、订阅与单次内容收费，核对用户和广告主、内容权利、获客留存及持续内容投入。 | 单一爆款不等于持续利润；旧报纸、广播和有线网络的地域优势不能直接搬到新渠道。 |
| 电信 | 用户、流失、服务组合、单位收入、网络利用、频谱或许可、更新资本及债务期限。 | EBITDA 不是自由现金流；高前期投入不能阻止资金充沛的进入者，所谓最后一轮升级需用后续支出验证。 |
| 生活消费品 | 量价与组合、品牌持续投入、渠道议价、产品创新、地区与汇率及现金分配。 | 不依赖景气的需求也可能被高买价抵消；削广告、促销和渠道压货可暂时美化盈利。 |
| 工业、材料、能源与公用事业 | 分清商品与差异化、上中下游、受管制与竞争性环节；按周期核对成本、产能、储量或网络更新及资金。 | 周期顶峰低 P/E、用历史商品价当长期底线、储量增补忽略并购成本、垄断地位忽略费率和资本约束。 |

零售和制造业周转可按同一期间的平均余额计算：`DIO = 平均存货 ÷ 销售成本 × 期间天数`，`DSO = 平均应收 ÷ 对应赊销收入 × 期间天数`，`DPO = 平均应付 ÷ 对应采购额 × 期间天数`，`CCC = DIO + DSO − DPO`。资料不足时，用销售收入或销售成本作代理须标明局限，并对齐税额、收购和季节性。负 CCC 要核查供应商议价及其可持续性，现金释放不重复永续化。

## 接入估值与交付

将已证实的优势反映在利润率、资本回报、增长范围和衰减期；不要再额外加一笔无法解释的“护城河溢价”。按[价值投资与企业估值](value-investing.md)和[证券分析](securities-analysis.md)计算价值、现金预算及报价隐含条件。金融、受管制或资源有限寿命业务使用适合的模型。

交付市场及经营方式图、优势证据表、增长与资金拆解、行业指标及反证、估值假设和复核触发条件。周期低谷、研发失败或股价下跌只触发研究，是否暂时取决于客户需求、竞争地位、整改证据与存活资金。组合成员按底层公司、指数或基金权重汇总共同冲击，不能把公司数量或基金只数当作独立风险源数量。

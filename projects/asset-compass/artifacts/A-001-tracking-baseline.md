## 4. 跟踪指标与计算口径

| 指标 | 拟定口径 | 当前可用性 |
|---|---|---|
| 实际投入执行 | 分别比较本期实际外部投入与本期计划，区分期中累计和已结月；组合内转账不重复计入外部投入 | 可开始核对已填记录，月度结论待月份结账 |
| 组合市值 Vt | 同一估值截止点的持仓市值、现金及确认的存款账面价值之和，按对应币种及汇率折算人民币 | 缺统一历史快照与部分口径，暂不发布正式总值 |
| 净投入 Ct | 跟踪起点之后流入组合的外部资金减流出组合的外部资金，包含账户范围确认，剔除内部转账 | 待实际日期和资金边界核对 |
| 期间投资盈亏 | Vt − V0 − Ct；V0 为已纳入持仓在跟踪起点的市值，历史取得成本另列用途 | 待 V0、Vt、Ct 一致；不把本金增加算成投资收益 |
| 目标进度与缺口 | Vt / 10000000；缺口为 10000000 − Vt，超过门槛时注明超过金额 | 待 Vt 可靠；进度比例不表示达标概率或时间进度达标 |
| XIRR | 投资者视角：期初 V0 及新增外部投入为负，外部提款为正，终点 Vt 为正；用实际日期，组合内再投资不重复记外部现金流 | 现金流或日期不足时不计算，不用零替代失败 |
| 配置与流动性 | 按实际持仓和现金估值计算敞口，分别说明资产、币种、可动用现金和受限资金 | 待统一估值、实际买入和存款限制核对 |
| 回撤 | 先确认适合持续现金流的收益/单位净值序列与观测频率，再衡量峰谷变化 | 尚不可计算；不直接以总资产峰值比较代替投资回撤 |
| 到期达标概率 | 对经过核实的情景直接统计 2036-12 市值至少 1000 万元的路径比例 | 目前不可验证；不以“翻倍概率”、均值或分位替代 |

XIRR 适用于非等间隔现金流，输入需要日期及至少一个正值和一个负值；失败应保留数据不足或计算失败状态。[Microsoft XIRR 文档](https://support.microsoft.com/en-us/excel/functions/xirr-function)，本轮核查于 2026-10-12。

模拟说明应明确方法、假设与限制，并区分假设结果和实际收益。本轮参考 [FINRA 2214](https://www.finra.org/rules-guidance/rulebooks/finra-rules/2214) 的披露方法，2026-10-12 核查；不据此推定该规则对本项目的适用性。

后续收束约定时可参考以下流程；第 1 项截止点及第 4 项提示条件当前保持待定：

1. 每月以月末为估值截止点。ETF 对应不晚于截止点的最近交易收盘；BTC、汇率及现金以明确时点和来源记录。各来源日期不同则在当期说明，缺值不自行猜补。月中材料可做期中核对，不能当作完整月度结果。
2. 用户在本会话提供或指出更新后的工作簿版本。投资顾问先核对哈希、变更月份和实际输入，再检查资金、持仓与估值是否对得上。每期工作按实际任务登记，不把本次初始化当作已持续跟踪。
3. 复盘呈现已核实的投入执行、市值与现金流变化、目标差距、配置和流动性，以及不可计算指标及缺口。实际发生、公式计算、模型情景和建议分别标明。
4. 补充复盘候选条件：投入计划变化或中断、出现组合外提款或配置调整、材料缺失或对账不一致。数值回撤和配置偏移阈值待风险约束确认后另行约定。
5. OPC 保存来源路径/哈希、月份、口径、异常及待决定事项和符合保存边界的复盘结论；持仓、余额和流水明细留在原材料。历史估值有更正时标明原版本、更正来源和原因，避免无痕覆盖。

本轮尊重用户明确保留待定的选择，不重复催促，也不默认启用月末截止或候选提示条件。下一份材料可先按其实际注明的时点核对，无法完整估值或计算的项目继续列明缺口。后续投资安排调整仍由用户决定；当前没有交易执行、账户接入或业务工作簿修订。

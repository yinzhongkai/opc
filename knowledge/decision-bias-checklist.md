# 判断偏差与决策检查

用于在研究、比较候选和复盘时发现容易被忽略的证据与行为诱因。主要根据《穷查理宝典》第二章、第四章第5、11讲及书内检查清单整理，[阅读范围与来源](../docs/poor-charlies-almanack-reading-notes.md)留档。书中25种倾向是作者的实用分类，存在重叠，不是完备、互斥或具有统一效应大小的心理学定律。下列问题和记录方式为方法转化，不复刻原书清单。

## 在形成结论前检查

先独立写出问题、关键证据和暂定判断，再接触他人的结论；需要按既有流程协作时，在允许范围内保留各自初始依据。为判断留出核查空间，紧迫感不能充当证据。无足够信息时可保持待研究状态，不把不知道改写成中性、低风险或确定否定。

将经济事实与判断过程分开核查：前者问现金、权利和条件是否成立，后者问为什么自己愿意相信它。二者都需要证据，心理解释不能替代财务、法律或技术核验。

| 检查方向 | 需要回答的问题 | 可采取的处理 |
| --- | --- | --- |
| 激励、互惠与自利 | 谁付费，谁定估值，谁按成交或短期数字领奖，谁承担延后损失？是否因礼物、合作关系而降低核查？ | 列出利益路径；复核原始资料与长期兑现；将防线落实到可检验的职责和控制 |
| 喜恶、关联与权威 | 是否因喜欢创始人、讨厌对手、熟悉品牌或敬重专家，就跳过了证据？ | 将人、主张和事实拆开；核对专家的具体领域、依据和边界；坏消息单独核查 |
| 承诺、沉没成本与损失反应 | 是否为了维护公开观点、成本价、已投入的研究时间，继续替原结论辩护？ | 从当前证据重新比较可行替代项；陈述最强反对意见；记录改变判断的条件 |
| 从众、嫉妒与错失压力 | 是否把同行购买、价格上涨或别人获利当作独立论据？ | 查实际机制和不同意见；保留独立估计；逆大众本身也不构成证据 |
| 过度自信、乐观与拒绝不利事实 | 是否高估自己、低估工期和损失，或用过去成功证明下一次也成立？ | 采用相关基准率、区间和失败情景；将有证据的优势与运气分开；及时记录坏消息 |
| 可得性、对比与叙事 | 是否被近期新闻、生动案例、旧高价或促销锚点支配？难量化但重要的因素是否漏掉？ | 使用完整的分母、历史区间及当前价值依据；补查未被叙事覆盖的数据和反例 |
| 压力、疲劳与知识失用 | 当前状态是否妨碍理解？关键但少用的步骤是否生疏？ | 在条件允许时分段复核、安排演练和休息；以实际能力检查为准，不按年龄推断能力 |
| 空洞语言与表面理由 | 是否有大量术语，却说不清因果、数值、责任和条件？“因为”后面是否只是重复结论？ | 要求可验证的解释，明确谁、做什么、何时、何处及为什么；无法解释处保留未知 |

这张表用于查自己的遗漏，不用来给他人贴心理标签。发现利益冲突、权威影响或群体一致时，仍须查证该主张；不能仅凭这些线索断言对方错误或有欺诈。

## 把激励分析落到可验证的控制

对影响结论的参与者记录“目标／奖励口径／信息优势／可转移的损失／约束及实际行为”。尤其检查放贷与持有风险是否分离、估值者是否从估值上涨获奖、顾问是否因成交获益、审查者是否依赖被审查方收入。

比较奖励指标与最终目标。销量、订单额、点击量和报告利润都可能与长期净现金或用户结果脱节。观察提前确认、延迟成本、挑选样本或转移风险的空间，并检查独立复核、现金核对、事后兑现及坏消息上报是否实际起作用。控制本身也有成本和副作用，应按真实风险安排；不能把信任理解为取消记录、必要监督或既有审批。

自拟例：贷款发起方按发放额收取费用，资金提供方承担违约损失。核查重点包括借款人偿付能力、材料真实性、风险留存及追索、估值假设、违约后的现金回收与审查者独立性。发起量增长或短期没有损失，都不足以证明质量提高。该例是风险核查，不是对具体机构的定性。

## 检查偏差叠加

不要给偏差打分后机械相加。列出实际链条，例如“乐观估计 → 公开承诺 → 依据短期指标获奖 → 同行复制 → 不愿报告坏消息”，说明各环节的证据、时间和可能中断点。与[多元模型与逆向推理](multidisciplinary-reasoning.md)一起检查反向反馈、延迟损失及共同失效。

结果也可能来自正常经济机制、数据错误、约束或偶然性。列竞争性解释和可区分它们的观察，避免看见一个失败就事后附会多种心理原因。

## 形成可复核的事前判断

在现有备忘录中保留以下最小记录，深度按影响和不确定性调整：

1. 截止日、资料与版本、问题和可行替代项，包括维持现状或补充研究。
2. 已知事实、主要假设与未知；相关基准率、估计区间及概率依据。无依据的概率明确留空。
3. 当前判断及最强反对论证；最可能推翻判断的证据、失败损失、兑现期和生存所需现金。
4. 自身及信息提供者的激励、承诺、关系和叙事影响，已做的独立核查及仍有的缺口。
5. 触发重新判断的事实、需要补证的责任接口和既有复核安排。技能不自行给其他成员分派任务。

证券研究使用[证券分析](securities-analysis.md)核实现金和权利，使用[估值与投资研究纪律](valuation-and-investment-discipline.md)统一价格、时间、成本和替代用途。组合研究另核实资金期限、共同敞口及被迫出售风险，不能由“有把握”推出集中仓位。

## 事后按过程和结果分别复盘

保留事前版本，比较预测和实际；将当时不可知的新信息另列，避免用事后结果改写当时证据。盈利可能伴随坏过程，亏损也不单独证明过程错误。分别记录事实或机制错误、假设变化、漏查、执行偏离和偶然因素，指出下一次具体应改变哪一个核查步骤。

同时查看未采取的候选，检查是否反复遗漏机会；比较须基于当时可行的资金、价格、信息和权限，不能从事后赢家倒推出当时应当知道。检查清单能帮助减少遗漏，不能保证消除偏差或获得收益。

心理学方法用于透明沟通、自我约束与提高判断质量。书中的强迫、欺骗、群体操控及医疗相关轶事不转化为工作指令；本文不提供诊疗结论，也不改变公共协作与授权规则。

# 项目经理

## 职责

- 依据已确认目标组织里程碑、任务负责人、依赖和风险。
- 维护团队任务计划，协调负责人、依赖、优先级、范围和完成条件。
- 跟踪真实进展、成果与阻塞，按项目指定承担状态汇总及协调记录维护。
- 把专业问题交给对应成员，将成员与知识缺口交给超级管理员。
- 组织专业交叉评审，协调评审范围与参与成员，跟踪意见、作者统一修订和复核。
- 评估成果涉及的任务依赖、交付安排与项目风险，提供项目管理意见。

## 边界

- 不以进度协调替代专业结论，也不擅自改变已确认目标和资源约束。
- 不作为自己直接制作产物的独立评审人。
- 项目经理身份不自动取得所有成果的最终确认权。
- 不替专业成员署名或作出专业结论。

## 主要产出

- 任务计划、项目状态、风险记录、交接、阶段总结、评审安排及本岗位评审意见。

## 月度留存规则

用户更新主文件后说明月份与阶段；投资顾问归档对应整份文件，再按 A-001、A-002 分析。文件内容有变化时按该月下一个序号新增；结月标记 closed，期中标记 interim，更正标记 correction，未确认结月时按期中处理。采集时刻与估值截止点分别记录，不通过文件修改时间推定完成月份。

同一月份、阶段和 SHA-256 的重复归档复用已有版本；不同内容不覆盖旧文件。同月更正保留此前副本，并在索引和复盘中说明原因。更新最新价格只影响主文件，留存副本供对应历史期核对，历史副本不要覆盖保存。

每次复盘后将主文件、快照及索引保存为本地 Git 版本，验证后在 OPC 同步成果物精确提交；WORKSPACE.revision 只引用已验证的 main 提交。远程推送、后台运行和账户接入不在本次安排内。

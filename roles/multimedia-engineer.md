# 多媒体工程师

## 职责

- 实现媒体探测、解封装、解码、格式转换、代理生成、编码与封装等多媒体管线。
- 维护媒体时间戳、可变帧率、音视频同步和项目规范时间之间的可验证映射。
- 处理长时与异常媒体的流式资源控制、取消、错误恢复和诊断，提供可复现的媒体测试证据。
- 向核心、算法、界面、构建和测试成员提供稳定的媒体接口与能力矩阵，评审影响媒体正确性和分发的变更。

## 边界

- 不擅自决定产品支持的容器、编码器、画质、性能目标或第三方许可证路径。
- 不改变系统规范时间、Worker/IPC、项目存储等公共契约；发现冲突时与对应负责人协调。
- 媒体文件可处理不等于内容正确、产品体验合格或具备发布授权，生产发布须走相应确认流程。

## 主要产出

- 多媒体模块代码、探测与时间映射接口、代理和导出管线、格式能力矩阵、自动化测试、性能与同步验证资料和开发交接说明。

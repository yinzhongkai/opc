# 构建工程师

## 职责

- 建立并维护可复现的编译工具链、构建配置、依赖获取、测试和打包流程。
- 管理编译器、SDK、运行库、构建类型及第三方二进制之间的 ABI 兼容边界。
- 将本地构建流程固化到 CI，提供可追溯的构建产物、日志、版本清单和故障定位证据。
- 向架构、研发和测试成员提供稳定的构建入口与环境契约，评审影响构建、依赖、打包和持续集成的变更。

## 边界

- 不擅自改变产品范围、系统架构或尚待确认的工具链决定。
- 构建成功不等于功能、性能或产品验收通过；不代替测试与最终确认人作出结论。
- 不因配置 CI 而自动获得生产发布、签名凭据、采购或第三方许可证决策权限。

## 主要产出

- 工具链基线、构建预设、依赖与 ABI 清单、可复现构建脚本、CI 配置、构建产物及构建交接资料。

# 研发工程师

## 职责

- 根据需求、架构和成员分工实现软件功能。
- 编写与变更相称的单元测试，修复缺陷并记录验证结果。
- 提供实现说明、调试证据和对接信息，配合相关成员完成联调。
- 按成员分工承担前端、后端等研发方向。
- 评审需求、架构和对接资料，检查实现约束、接口可用性、依赖与异常处理。

## 边界

- 不擅自改变产品范围和架构关键决策。
- 不批准自己的实现通过独立评审；生产发布须有相应任务授权。

## 主要产出

- 代码、单元测试、实现说明、开发交接资料和研发评审意见。

## 读者与阅读结果（D-001 已确认）

- **首要读者**：项目用户本人——按照 PROJECT 的图书工作方式，用户是本书的第一位学习者和反馈来源。
- **读者画像（已确认）**：熟练 C 语言与系统编程，熟悉芯片硬件原理与驱动开发（用户背景：Linux 内核开发，地平线 XJ2/XJ3/J5/J6 平台，稳定性与性能优化）；**无单片机与 RTOS 经验，无蓝牙开发经验**（BLE 是其重点学习目标）。
- **画像对写作的要求**：C 语言、寄存器/中断/控制器原理不讲解；devicetree 与 Kconfig 借力读者的 Linux 背景，重点放在 Zephyr 特有用法与差异；**RTOS 概念是正式起点**（线程、调度、同步、无 MMU、ISR 上下文），并以 Linux 内核概念作对照讲解（如 k_work 之于 workqueue）；BLE 从零讲起并作为全书主线经营。
- **出版意向（已确认）**：本书以正式出版/发布为长期目标，现阶段以自用学习迭代。写作约定按出版标准执行：事实性主张标注可追溯来源、插图自制或有使用依据、术语全书一致；具体出版形式、时间与渠道待内容成型后另行确认。
- 阅读并跟随实践后，读者应能（将随目录逐章落到可观察结果）：
  1. 在 Windows 主机上独立完成 NCS/Zephyr 开发环境搭建、工程创建、构建与烧录；
  2. 解释 Zephyr 工程结构，以及 devicetree 与 Kconfig 在硬件描述和功能配置中的作用；
  3. 使用 Zephyr 内核服务（线程、调度、同步、中断、定时、工作队列）组织应用程序；
  4. 通过 Zephyr 设备驱动模型操作 nRF54L15 的主要片上外设，并理解 DPPI 外设互连的低功耗价值；
  5. 实现 BLE 广播、连接与自定义 GATT 服务，并理解安全配对的基本概念；
  6. 使用 DK 的电流测量能力评估并优化低功耗表现；
  7. 完成固件空中升级（BLE DFU），并了解量产烧录与认证的基本路径。
- 使用方式与反馈：用户按章节照做并反馈结果；反馈的具体格式、频率与验收范围待任务规划时确认（PROJECT 已声明为待确认项）。

## 内容取舍（D-002 已确认）

- **主线与组织方式**：以 Zephyr RTOS 学习为主线、nRF54L15 DK 为首发实践平台，按"环境起步 → Zephyr 基础 → 芯片外设 → Zephyr 系统服务进阶 → BLE 应用 → 低功耗与产品化"推进；每章围绕可观察、可验证的学习结果组织，见配套 [全书目录](outline.md)。
- **已确认覆盖范围**：开发环境与构建系统（CMake / devicetree / Kconfig）、Zephyr 内核基础、Zephyr 系统服务（k_work、线程栈管理、Shell、settings/NVS、电源管理子系统）、外设实战（GPIO、UART 与日志、定时器/PWM、I2C、SPI、ADC 与 DPPI）、BLE（协议概念、广播、连接与 GATT、安全、功耗优化）、分区布局与 BLE DFU、产品化概览（量产烧录与测试认证入门）、FLPR RISC-V 协处理器进阶篇。
- **已确认排除的主题**（最多在行文中一句话提及，不做实战）：Matter / Thread / Zigbee 与 2.4 GHz 私有协议、LE Audio、蓝牙信道探测（Channel Sounding）、nRF52/nRF53 迁移指南、自行设计硬件（官方硬件设计指南 ngl_001 仅作参考）、手机端 App 开发。
- **I3C 明确不讲**：经 940 页芯片数据手册全文检索确认 nRF54L15 无 I3C 控制器（I3C 为 nRF54H 系列特性），硬件不支持，从本书移除。
- **与已有资料的关系**：以用户下载的 Nordic 官方资料包和 NCS 官方文档为一手来源；Nordic DevAcademy 免费课程作为学习参考，本书不复制其课程结构；不虚构市场调查结论。
- **篇幅（已确认）**：不设总篇幅与每章统一长度，每章以"一个可验证的学习结果"为自然边界。

- 技术结论按证据分级：官方资料/源码核查、构建与自动测试、用户实机操作分别记录，不互相冒充；用户执行的结果明确标为"用户执行/用户报告"。

- **开发主机（已确认）**：Windows；环境搭建章以 Windows 为主线（nRF Connect for Desktop / Toolchain Manager / VS Code 的 Windows 路径），其他系统差异最多作附注。用户尚未安装任何开发软件，第 1 章从零安装写起。

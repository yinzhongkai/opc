## 归档规则

文档按用途维护一份当前版本：PRD 说明产品要实现什么，TRD 定义技术要求与验收，算法说明记录具体原理和实现逻辑。项目管理文件继续承担各自职责。

- 新增成果应标明项目、成果编号、版本、状态、确认来源、适用范围及关联任务。
- Draft 可用于评审和继续澄清，不自动成为研发或测试执行依据。
- 批准、替代或撤回成果时，同步更新 [PROJECT.md](../PROJECT.md)、[DECISIONS.md](../DECISIONS.md)、[TASKS.md](../TASKS.md) 和 [STATUS.md](../STATUS.md)。
- 按用户于 2026-09-06 确认的规则（SR-D009），中间草稿、过程报告、清理记录及其备份不保留；有独立价值的技术分析整理为单独交付文档，记录算法、适用范围和验证状态。后续内容更新到对应文档，不再另建冗余副本。

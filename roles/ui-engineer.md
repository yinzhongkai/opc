# 用户界面工程师

## 职责

- 把已确认的用户流程转成信息架构、交互原型、界面状态和可实现的视觉组件规范。
- 实现桌面或客户端界面、视图模型、数据模型适配、输入交互、错误与恢复呈现。
- 维护界面组件复用、响应性、可访问性、高 DPI 和自动化 UI 测试边界。
- 向核心、媒体、图形和测试成员提供清晰的界面消费契约，评审影响用户工作流的实现变更。

## 边界

- 不擅自改变产品范围、业务优先级或核心数据语义。
- 不把媒体解码、DSP、计算机视觉或大数组处理放入声明式界面脚本。
- 不以视觉完成代替功能、性能、可访问性或产品验收，生产发布须有相应授权。

## 主要产出

- 交互原型、界面状态与组件规范、客户端界面代码、视图模型适配、UI 自动化测试和开发交接资料。

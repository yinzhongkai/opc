# 可灵制作检查与迭代

适用于视频制作与后期成员执行可灵镜头制作、检查及返工，导演和视觉设计师按自身职责协作。以官方已读用法为依据，以下生产记录、检查表和返工流程为整理者补充，不表示已经实测模型效果。来源及未读范围见[阅读记录](../docs/kling-ai-source.md)。

## 从小样进入制作

核对已确认的镜头表、参考集、[入口与模型](kling-model-selection.md)、[提示词](kling-storyboard-prompts.md)及[素材职责](kling-reference-assets.md)。选一个有代表性的风险镜头：转头、多人发声、手与物接触、产品文字、复杂运动或场景连续性。先规定需要验证什么，再检查实际输出。

最终输入应包含模型全名与入口、完整提示词、各参考用途、时长、画幅、分辨率、声音和分镜设置、输出数量及费用依据。任务要求“准备”或“预览”时，停在可审阅的方案；需要提交生成时，按用户当前授权和实际工具流程执行，不把读取文档当作生成授权。

## 记录一次生成的事实

```text
镜号 / 候选号 / 配方版本：
生成时间、实际使用的服务与入口、完整模型名：
输入素材与版本 / 当前引用 ID / 各自职责：
完整提示词 / 时长 / 比例 / 分辨率 / 声音 / 分镜 / 数量：
报价依据及时间 / 余额检查 / 用户授权来源：
任务 ID / 提交结果 / 当前状态：
返回的实际扣费（若有；否则写未知）：
输出文件与版本 / 实际时长 / 播放检查范围：
采用、修订或淘汰及原因 / 后续版本关系：
```

不虚构随机种子、帧率、色彩空间、可重现性或实际扣费。提示词相同不证明输出相同；报价、提交次数与服务实际扣费分别记录。

当前 Kling AI 插件要求提交前核对实时能力与费用，并限制同一次明确生成请求的提交次数。遵循当次插件技能，不能把超时、未知状态或失败响应当作允许自动重复扣费生成的信号。

## 已有任务优先查询

取得任务 ID 后围绕该任务跟踪状态，保留失败原因与输出关系。提交响应不明确时记录“是否已建任务、是否扣费未知”，避免重复提交制造重复任务。结果链接过期时优先从原任务刷新，不能直接重生替代。

将已提交、处理中、失败、成功返回、文件可打开、质量检查通过分别表述。只有实际播放了画面与声音，才声称检查了它们；只有预览封面时就标明只检查封面。

## 镜头与成片检查

| 维度 | 观察内容 | 检查方式 |
|---|---|---|
| 信息与表演 | 关键动作、情绪转折、对白和节奏是否成立 | 按正常速度连续观看，定位镜号和时间码 |
| 身份与资产 | 脸、发型、衣着、道具、产品结构、场景和文字 | 对照明确版本的参考；检查中间帧而非仅首尾 |
| 运动与物理 | 肢体、手指、接触、重量、遮挡、方向和动作完成度 | 对高风险段落逐段复查 |
| 镜头与连续性 | 轴线、视线、位置、机位、景别、切换和动作接续 | 连播相邻镜头，检查切点两侧 |
| 声音 | 说话人、逐字台词、语言、音色、口型、环境声和配乐 | 实际收听并检查声画同步 |
| 技术交付 | 时长、画幅、清晰度、帧率、黑帧、闪烁、字幕安全区 | 检查最终导出文件，不只看时间线预览 |

工具宣称能保持文字或身份，不代替实际检查。生成画面带有字幕也不表示准确；与用户确认文案逐字核对。声音生成更完整也不免除剪辑、调色、配音和混音工作。

## 按问题返回正确环节

| 问题 | 优先排查和调整 |
|---|---|
| 人物外观或产品结构漂移 | 素材质量、身份参考职责、主体绑定及转头所需视角 |
| 角色串台、音色混淆 | 稳定角色名、台词归属、说话顺序、音色绑定冲突 |
| 动作赶不完或途中崩坏 | 事件密度、接触与空间条件；拆动作、调整时长或分镜 |
| 出现额外切镜 | 多镜头默认行为、首尾差异、相互矛盾的连续性要求 |
| 编辑改坏无关内容 | 是否明确编辑原视频、变更对象和保留项；整段对比 |
| 提交参数不被接受 | 实时模型与工具 schema；不根据旧文档随意猜字段 |
| 成片无聊或信息不清楚 | 回到镜头目的与叙事结构，不靠不断重生成解决 |

每轮围绕一个明确假设改变少量变量，保留前后配方和结果。需要修改剧本、视觉基线或交付范围时交相应责任人；不能以技术修复名义擅自改创作事实。多镜头作为一个任务的方案，不自动授权按每个镜头分别提交付费任务。

## 交付依据

交付可播放的成片、可编辑工程、采用素材与版本清单、必要生成记录、技术检查及未解决项。成本评价关注每个最终可用镜头或整片的实际总投入，不只比较单次生成单价。叙事意见、技术自查、专业评审与用户最终批准分别记录，遵循项目既定协议。

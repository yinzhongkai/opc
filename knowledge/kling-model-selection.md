# 可灵模型与创作入口选择

适用于用可灵制作剧情、广告、动画、口播等视频之前的方案选择。主要使用者是导演和视频制作与后期。资料核对截至 2026-11-26；[来源与阅读覆盖](../docs/kling-ai-source.md)记录实际读到的章节及缺口。这里的能力是文档快照，不能代替当前账号、产品入口或插件的实时能力。

## 先明确任务，再选模型

记录内容目的、观众、发布画幅、总时长、镜头结构、声音要求、必须保持的角色或产品信息，以及已有素材。把硬性要求与可调整项分开。用户只要求提示词、分镜或方案时，完成相应文本即可，不检查账号、上传素材或提交生成。

优先问“需要控制什么”，再决定模型和入口：

| 需要控制的问题 | 候选入口或方法 | 选择依据 |
|---|---|---|
| 从文字探索创意、组合人物场景、参考视频动作或镜头 | 全能参考 | 为每个素材声明职责；没有参考时也可从文字开始 |
| 固定某个时刻的构图、首尾状态或中间叙事节点 | 关键帧 | 检查节点间的时间与运动是否可实现 |
| 保留已有视频，定向改角色、背景、动作或风格 | 视频编辑 | 明确要求编辑哪个视频、修改范围和保留范围 |
| 将特定人物动作和表情迁移到目标角色 | 动作控制 | 准备人物图与动作来源；检查朝向、面部与动作覆盖 |
| 用确定的配音驱动较长口播 | 数字角色 | 角色图、配音和表演描述分别准备，不套用短视频模型的时长 |
| 给已经制作的视频重新匹配口型 | 对口型 | 区别于一次生成画面与声音；核对声音长度与完整面容 |
| 先制作角色、多视图或分镜静帧 | 图片生成、图像编辑或组图 | 静帧通过检查后再进入视频制作 |

## 文档中的版本差异

以下用于排除明显不兼容的方案，实际提交前仍须复核。

| 版本 | 已读文档中的主要差异 | 使用提醒 |
|---|---|---|
| Kling 4.0 | 全能参考与关键帧两个入口；单次 3–30 秒；多关键帧最多 10 张；列出 720p、1080p、4K | 两入口当前不能在同一任务混用。HDR 和最长两分钟续拍在正文标注“即将上线”，不当作已可用 |
| Kling 4.0 Flash | 面向快速尝试；3–20 秒、720p；FAQ 说明暂不支持首尾帧及多关键帧 | 不能只因名称含 4.0 就套用完整模型能力 |
| 视频 3.0 | 3–15 秒；原生音画；智能分镜与自定义分镜；图生视频可绑定主体 | 自定义分镜以智能分镜开启为前提；主体绑定和音色按此版本的规则处理 |
| 视频 3.0 Omni | 多模态参考、视频角色与音色、3–15 秒及自定义分镜；编辑与视频参考承接 O1 用法 | 输入视频会改变可组合的图片/主体数量与费用；不能沿用 4.0 的额度 |
| 视频 O1 | 参考生成、指令编辑、前后镜头生成；3–10 秒 | 属于旧版工作方法参考；原生声音与多镜头能力不能从 3.0 Omni 倒推到 O1 |
| 视频 2.6 | 文生/图生音画，5 或 10 秒；语音以中英文为主 | 已读说明中的音色控制限图生音画，三人以上音色区分较弱；不套用 3.0 的语言列表 |
| 数字角色 2.0 | 角色图、配音、表演描述；文档宣称最长五分钟 | 适用于表演驱动的长口播，不能据此声称全能参考可单次生成五分钟 |

4.0 全能参考的文档快照：图片最多 10 张；视频最多 5 段且合计不超过 30 秒；主体最多 7 个，其中视频主体最多 3 个；音色最多 3 个；各类输入合计最多 15 项。参考视频、编辑视频和视频主体共用视频额度。素材数量上限不是每种素材都能同时用满；先按总量和共享额度核算。

文档同时存在概览、参数表、FAQ 和旧版页面，偶有上线状态或参数口径差异。发现矛盾时记录差异，以当前所用入口的实际选项或工具 schema 核验，不自行拼成一个“全功能模型”。

## 产品页面与插件调用分开核对

网页/App 功能不证明 MCP、API 或本会话工具已提供同样能力。操作前保存当前可用的模型全名、入口、参考槽位、时长、分辨率、比例、声音、分镜、输出数量和素材限制。无法匹配硬性要求时说明缺项，提出拆镜或换入口等选择，不静默降低规格。

使用 Kling AI 插件时，按当前安装技能和实时工具定义执行账号检查、素材绑定与计费检查；不在 OPC 知识中复制易过期的接口字段或认证实现。不能因插件已安装就宣称账号已连接，不能索取用户 cookie、令牌或密钥来绕过连接流程。

## 费用与试制选择

旧文档的价格只证明当时的计费方式，不作为报价。当前模型、声音、音色控制、输出分辨率、输入视频和时长都可能影响费用。生成前核对当前计价口径、预估与余额，并说明最终参数及参考用途。

探索时可选兼容的快速模型或较短代表镜头；正式输出按交付规格选择。先验证一个最能暴露身份漂移、多人对白或复杂动作问题的镜头，再决定是否扩大制作。样片成功不意味着其他镜头无需检查。

## 交给下一环节的信息

输出一份选择说明：目标与硬性要求、候选方案、采用入口与完整模型名、选择理由、实际可用参数、参考职责、费用核对时间、未满足项和下一步。分镜写作见[可灵分镜与提示词](kling-storyboard-prompts.md)，素材准备见[可灵主体与关键帧素材](kling-reference-assets.md)，生产记录见[可灵制作检查与迭代](kling-production-iteration.md)。

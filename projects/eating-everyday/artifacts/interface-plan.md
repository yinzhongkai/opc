首版围绕一个主页完成选店：上方切换菜单和搜索附近，中间转盘抽取，下方编辑候选并保存。菜单管理、保存和抽中结果使用弹层，让用户完成一轮选择时保持当前候选的上下文。

## 页面结构

| 区域 | 内容与入口 | 设计目的 |
|---|---|---|
| 标题 | 今天吃什么、简短说明 | 延续截图中的标题、纸纹及配色。 |
| 当前菜单 | 菜单名称与切换入口、未保存改动提示 | 让用户知道当前使用哪份菜单以及是否需要保存。 |
| 附近搜索 | 1、3、5 公里选择，默认 3 公里；“搜索附近餐厅” | 距离选择与实际搜索分开，主动点击后才更新候选。 |
| 转盘 | 顶部指针、分区候选、中心“开吃” | 把随机选店作为主操作。 |
| 候选编辑 | 数量、店名输入、“加入”、带移除入口的候选标签 | 只填店名即可补充；能检查和删除所有候选。 |
| 菜单保存 | “保存这份菜单” | 明确保存整个当前候选，避免搜索和增删时自动覆盖。 |

视觉采用奶油纸纹、深蓝绿色文字和轮廓，转盘扇区使用橙、黄、浅蓝与米色。长店名在候选列表完整换行。建议 12 项以内在转盘显示简称，完整名称保留在列表；超过 12 项时用编号对应列表，以兼顾最多 24 项的辨认。该呈现方式待用户评估。

## 关键操作

| 操作 | 交互与状态 | 需求或验收对应 |
|---|---|---|
| 加入店名 | 去首尾空白；空白与重复手动项提示；成功后列表及转盘同步更新，标记未保存。 | R-04、P-03；AC-03、AC-11、AC-12。 |
| 删除候选 | 从当前列表移除并标记未保存；保存菜单暂不变化。 | P-04、P-05；AC-13、AC-15。 |
| 重新搜索 | 保留手动项，按剩余容量加入最多 12 家合格地图餐厅；无结果、失败或无容量时保留原候选并说明。 | R-09、P-08、P-09；AC-02、AC-19、AC-21 至 AC-26。 |
| 抽取 | 0 项提示添加；1 项直接结果；多项转动后结果弹层只展示店名，提供“再抽一次”和“就这家”。 | R-03、R-05、P-02；AC-04、AC-09、AC-10。 |
| 保存 | 命名新菜单；已有菜单可明确覆盖或另存为新菜单。完整候选共同保存。 | R-06、R-07、P-05；AC-05、AC-15、AC-16。 |
| 切换菜单 | 无改动直接加载；有改动先选“保存并切换”“放弃并切换”或“取消”。 | R-08、P-05；AC-06、AC-17。 |
| 菜单管理 | 展示多份命名菜单及候选数量，支持加载、重命名和删除。 | R-07、P-04；AC-05、AC-14。 |

抽取动画期间暂时禁用候选增删、搜索及菜单切换，避免候选在一次抽取中变化；结束后恢复。减少动画偏好下直接呈现结果。确认弹层保留清楚的关闭入口，长店名不截断为无法辨认的结果。

## 初始与异常状态

| 状态 | 页面行为 |
|---|---|
| 没有候选 | 保留搜索、添加与加载入口；点击开吃提示先添加，不产生店名。 |
| 定位未授权 | 提示可以继续手动添加或加载菜单，不阻断已有候选抽取。 |
| 搜索失败或筛选后无结果 | 保持当前候选和已保存菜单，提示本次未更新。 |
| 总数已满 24 项 | 新增提示先删除；手动项已占满时，搜索也不挤掉已有项。 |
| 加载旧菜单或位置变化 | 原候选保持；仅用户再次点击搜索才按更新规则处理。 |
| 本机菜单留存 | 正式产品应验证正常关闭后可加载；清除数据或换机不要求恢复，见 AC-07、AC-20。 |

## 演示范围及验证记录

[交互演示](meal-wheel-preview.html)使用虚构餐厅及示例菜单，位置文字仅展示用户指定的测试区域。搜索使用模拟结果，未请求定位、未调用真实餐厅接口。演示中的保存只用于预览交互状态，不代表微信小程序本机存储已经实现或验收通过。

首屏默认 10 个模拟地图项加 2 个手动项。3 公里模拟搜索最多返回 12 个地图项，1 公里示例返回 4 个；数量仅用于演示不同状态，不是林萃桥实际门店数量。可在预览设计选项中切换正常、无结果、失败和定位未授权状态。

本轮通过浏览器检查页面呈现，并逐步核对候选添加及重复提示、搜索保留手动项、未保存切换、保存后切换、命名另存、抽中结果以及 0/1 项处理。修正了预览环境中候选添加按钮的交互，并回归检查。24 项上限、异常搜索与窄屏仍待补充浏览器验证；此处不代替 A-001 的正式产品验收。

## 后续需收敛

1. 用户对主页顺序、候选数量较多时的编号呈现及弹层操作的反馈。
2. 已许可数据源如要求来源标注，应在搜索或候选区域落实；抽中结果仍按 R-05 只展示店名。
3. 真机上长店名、键盘弹起、定位权限和本机持久保存需在实际小程序中验证。当前工作区为 none，本轮仅产出方案治理成果。

# 投资资产与合约风险分析

用于把资产名称、名义收益和账面计量还原为持有人实际拥有的权利、现金流及共同承压条件。依据《巴菲特致股东的信：投资者和公司高管教程（原书第4版）》第2章 G、第3章及相关风险讨论整理，[来源与覆盖](../docs/buffett-shareholder-letters-reading-notes.md)留档。条款、受偿顺位和现金预算的通用步骤使用[证券分析](securities-analysis.md)，组合汇总使用[投资组合分析与跟踪](investment-analysis.md)。本文补充资产特性和合约相互依赖的检查，算例自拟。

## 先按经济来源分类

| 类型 | 收益与风险核查 |
| --- | --- |
| 货币计价的索取权 | 分开计算名义支付、违约或延期、利率、税费和通胀后的购买力。现金与短期债的流动性用途另列，不能因长期购买力风险否认其近期支付作用。 |
| 不产生可分配现金的资产 | 识别消费或使用需求、存储和交易成本、供需及退出买家；不能套用企业盈利折现。价格上涨所需的未来需求及成交条件需要独立证据。 |
| 生产性资产 | 核查客户需求、定价权、维持与成长资本、税后可分配现金及竞争衰减。名义利润增长若被新增资本吞没，不能直接当作实际收益。 |

分类是提出问题的起点。名义本金稳定、低历史波动或信用评级，均不能单独证明税后实际购买力安全；波动也会通过抵押品、追加资金及被迫卖出变成现金损失。历史资产偏好不直接形成当期配置建议。

## 信用、零息与优先权益

1. 先按法律主体列现金利息、累计利息、本金、必要经营投入及实际资金来源。检验正常和衰退时期的现金偿付，另按抵押、顺位、执行时间与费用估回收。高票息、低发行价与实际回报分别列出，不能用票息抵消未经测算的本金损失。
2. 比较高收益债样本时，区分发行时即低评级与事后降级，核对年代、违约定义、回收时滞及未存续样本。发行和承销激励、限制性条款及融资窗口会改变质量，历史均值不能自动套入新证券。
3. 零息债列购买价 `P`、到期支付 `F` 和剩余年数 `T`；无其他现金流且按约到期支付时，年复合收益为 `(F/P)^(1/T) − 1`。再分别测试提前赎回、违约、税款先于现金收到及出售价格。政府债拆息产生的现金流与企业新增信用融资需分别分析。
4. 实物付息或递延付息列逐期余额及复利：无需当期付现不代表没有资金成本。核查到期偿付是否依赖再融资、资产出售或尚未兑现的增长，现金利息减少不能抵消债权持续累积。
5. 优先股将固定分派、欠息累积、清算权、表决触发、赎回和转换分别建表，注明选择权属于谁、强制条件和上行上限。优先顺位仍可能在资产不足时受损；将税后分派与普通股及债券的实际权利、价格和机会成本比较。

自拟例：零息债以 60 买入，五年后按约收回 100，到期年复合收益约 10.76%；若仅收回 70 且推迟到第七年，约为 2.23%，未扣税费。100 的本金按 10% 实物付息、三年无现金支付且无其他变动，会累积为 133.10。账面利息收入与实际到账须分开。

## 衍生品与模型计量

- 用合约条文画出支付条件，注明买方或卖方、参考资产、名义额、期限、币种、结算方式及行权人。名义额、公允价值、抵押品和可能损失分别计量，不能互相替代。
- 列对手方、净额结算的法律有效性、抵押品可用性、评级或价格触发、补仓期限和提前终止条件。把市场下跌、对手方违约及抵押品缩水同时测试，检查风险最重时担保是否也失效。
- 区分模型利润、会计利润和现金结算。核查估值输入、退出报价、模型储备和奖金时点；长期合约的未实现利润可能先进入激励，而损失与流动性需求很晚才出现。
- 对长期期权，不机械外推短期历史波动率或把模型概率当作已验证事实。逐情景检查尾部支付、期限、分红、行权结构及资金存活条件；无法可信估计的参数应保留区间或不作定量结论。
- 对冲先说明覆盖的经营风险与期限，再算保费、融资、展期、基差和错配。压力时测关闭、替换合约的成交能力及现金成本，账面抵销不保证资金需求抵销。

## 跨币种与房屋融资的具体检查

按收入、成本、债务、资产和抵押品分别列币种，另算投资者基准币种回报。海外业务不等于该证券报价币种敞口，对冲收益还需扣除持有及展期成本。宏观观点要落到企业现金与权利；历史贸易和汇率论述不能当作当前预测，经常账户与财政收支需区分。

房屋融资或相关信贷先核实收入、真实首付款、生活支出、还款额及追索责任，分别测失业、收入下降、利率变化和抵押品价格下跌。把发起费用与长期持有损失的承担者对应起来；证券化改变风险持有人，不消除系统总损失。信用分数不能代替偿付能力分析，升值和再融资不能作为唯一还款来源。

## 汇总现金依赖和同时失效

建立按主体和日期的义务表：经营、到期债务、保险赔付、保证金、评级触发和担保。可用现金需扣受限和维持经营部分；未落实再融资和授信单列，不能与已到账现金等同。检查集团内资金能否及时合法转移，合并现金余额不能代替担保主体的支付能力。

保险浮存金和递延税可形成长期资金来源，同时仍有赔付、税款及使用约束；其成本与持续性需要验证。原书伯克希尔的现金储备数额、融资待遇和衍生品条款属于特定历史情形，不能复制成其他发行人或个人的安全门槛。

交付资产来源分类、权利及逐期现金表、模型与实际支付差异、正常及共同压力情景、关键证据和复核触发条件。研究方法不增加交易、借贷、衍生品使用或账户权限。

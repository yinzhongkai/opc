# 所有者导向的治理与资本配置

用于研究管理层怎样使用股东资本，以及经营成果能否归属于所研究的股份。方法参考《巴菲特致股东的信：投资者和公司高管教程（原书第4版）》全书，重点来自开场白、第1、4、5章及后记；覆盖见[阅读记录](../docs/buffett-shareholder-letters-reading-notes.md)。下列步骤是 OPC 的方法整理，算例为自拟。证券权利与财务输入按[证券分析](securities-analysis.md)核查，估值按[价值投资与企业估值](value-investing.md)建立。

## 先确定谁拥有收益，谁能作决定

记录发行主体、实际研究的股份类别、经济权益、表决权、控制人、董事会任免和重大交易决策权。对双层股权、控股平台及少数股权，分别核查经营现金流、可向持有人分配的现金和实施权。控制人的长期取向需要用交易和分派行为验证。

将研究边界写成可回答的问题：公司过去新增的一单位资本去了哪里，产生多少可持续的税后回报，普通股持有人为此承担了多少稀释和风险。经营规模、报告利润和每股价值分别追踪。

区分无控制股东、控制股东兼任经营者、控制股东不参与经营三类情形，分别核查谁能纠正经营失误和更换高管。董事报酬占其收入的比重、自有资金承担的损失、商业判断能力及实际异议记录，比形式上的独立标签更能解释监督激励。继任计划同时覆盖经营、资本配置与投资管理，并检查突发缺位和能力逐渐下降的处理机制。

## 核查披露和管理层行为

| 核查对象 | 具体动作 |
| --- | --- |
| 信息完整性 | 对照年报、附注、分部数据和管理层讨论，检查经营驱动、必要投入、负债及失败项目是否有解释。为调整后指标保留与报表的调节表。 |
| 披露一致性 | 按日期保存原承诺、指标定义、后续结果和解释。指标被删除或定义改变时，用可比口径重建；无法重建则记录缺口。检查不同公开渠道信息是否一致、是否同时可得。 |
| 盈利指引压力 | 将增长目标与市场容量、投入和实际现金回收对照。检查为达标而延后维护、提前确认收益或反复调整费用的迹象，进一步查证其业务解释。单一异常不足以判定欺诈。 |
| 管理和监督 | 区分经营能力与资本配置能力。查董事能否独立评价、制约或更换经理人，控制人是否参与经营，关联交易如何决策，以及少数股东可用的救济。制度名称和独立董事比例只作线索。 |
| 激励 | 列出指标、期间、资本占用、授予价格、归属条件、重定价和下行承担。检验奖金是否仅因留存增加、行业顺风或股价上涨而提高，是否鼓励牺牲长期竞争力。 |

经营考核优先比较经理人能影响的单位成本、客户质量、现金创造及资本回报。采用资本费用或同业基准时，解释资本基数和机会成本。记录管理层承认错误、修正配置的事实，并与一贯的宣传说法对照。

对固定行权价期权，分开检验留存资本、派息政策、回购和市场倍数的影响，不能把单纯积累资本形成的股价上涨全部归为经理人贡献。把授予、归属、兑现和离职条件与真实经济成本及下行承担对齐；同业薪酬排名与顾问推荐需核查利益冲突。

核查风险与声誉责任是否最终落实到能够决策的高管，坏消息能否及时上报，奖励是否在风险兑现前支付。可向审计披露提出四类问题：若由审计者负责列报会怎样调整、还缺哪些有用信息、内部控制有何偏差、哪些处理改变了跨期盈利。公开证据不足时列为待核查，不能假定已经获得审计者答复。声誉风险还应检查虽可能合法但会损害客户、员工或交易对手信任的行为。

## 识别经营约束和社会承诺

- 对结构性衰退业务，拆开管理效率、行业需求和竞争规则。若所有竞争者都必须追加设备并把节约让给客户，资本开支可能维持生存却不提高股东回报。与有序退出比较未来现金消耗、资产真实变现额、员工安排和履约成本，账面或重置价值不能直接当作清算收入。
- 对公用事业、铁路等重资本业务，核查必要维护是否高于折旧、允许回报及监管承诺、长期资产与融资期限、母公司担保和现金上划限制。原书企业的信用条件与现金底线不构成其他公司的通用标准。
- 对长期持有、保留管理层、就业及捐赠承诺，明确决定权、受益人、成本承担者和困难时期的履约事实。区分公司经营利益、经理人个人偏好与股东授权；持续经营的社会责任和无限期承担不可逆现金损失需要分别评价。历史捐赠及税务安排须按实际任务重核规则。

## 在同一预算中比较资本用途

先扣除维持经营、竞争地位及已承诺义务所需资金，核实现金所在主体和可调动性；再按未来现金流、时间、风险和机会成本比较可选择的用途。所有候选均测试融资收紧和经营恶化，现金不能同时分配给两个方案。

| 用途 | 核查依据 |
| --- | --- |
| 内生再投资 | 将存量业务自然产生的利润，与新增项目带来的利润分开。逐项记录投入时点、追加资金、税后增量现金、达产期和退出残值，检验回报是否超过相应资本成本。 |
| 收购 | 列入购买价、承接债务、费用、整合投入及维持投入。协同单列依据、实施权、成本和失败情景，与购买其他企业少数股权、回购、偿债等实际替代用途比较。 |
| 股票对价 | 同时估计取得的资产价值与新发行股份让渡的经济价值，比较交易前后原股东持有的每股价值。市场对价低不代表经济成本低；不能只凭合并后 EPS 上升判断交易划算。 |
| 回购 | 检查经营及流动性得到保障后的资金、保守每股价值、实际成交价和交易容量。回购公告金额、实际支出和股数净减少分别列示，核对同期增发与股权薪酬。 |
| 分红、偿债或保留现金 | 按股东取得的税后现金、到期债务、资金可用性及放弃的投资机会比较。保留现金需要解释用途、等待成本及复核条件。 |

对留存资本做跨期检验：原有核心业务的高回报可能掩盖新增收购的低回报。按项目或分部追踪新增投入及对应成果，匹配投产滞后，调整并购范围、股数及周期变化。将“留存能否增加至少等额价值”作为需要证据的检验问题；短期市值变化会混入估值倍数，不能直接证明资本配置成败。

## 深查收购及出售决策

1. 在接触交易叙事前记录独立价值区间及替代用途。检查扩张规模、薪酬、交易活跃度和融资便利是否推动了交易；卖方掌握的信息与出售时点可能造成判断偏差。预测需要客户、成本、资本和执行证据支持。
2. 用一张对价桥区分股权购买价、承担债务及取得现金，避免与企业价值口径重复相加；补入费用、或有对价、整合、后续维护及成长资金。协同按实施权、实现时间、成本和获益方单列，失败情景不能沿用全额协同。
3. 经营效率可用适当的有形经营资本衡量；评价收购是否成功仍用实际支付的全部经济成本，包括商誉。减值或核销不能抹去原投资成本。股票支付同时核算原股东让渡的内在价值。
4. 杠杆收购拆解经营改善、税盾、资产出售、债务杠杆和退出估值的贡献，列出管理人自有资本、费用、分成与亏损承担。税盾能否兑现及债务压力分别验证。
5. 特定股东高价退出的回购，检查是否由其他股东承担管理层维持控制的成本。出售企业或选择买家时，把现金价格与付款能力、担保、经营承诺、控制权、退出约束和历史履约一起比较。原书的长期收购偏好不等于所有企业永不出售。

## 回购的可复算检验

假设回购前普通股内在价值总额为 `V`，已包含本次可支配现金；股数为 `N`。以每股 `P` 支出现金 `C`，不考虑税费、新融资、经营变化和同期发行，则：

`回购后每股价值 = (V − C) ÷ (N − C/P)`，要求剩余股数大于零。

自拟例：`V = 1000`、`N = 100`，原每股价值为 10，现金支出均为 100。按 5 回购，剩余 80 股、价值 900，每股为 11.25；按 20 回购，剩余 95 股，每股约 9.47。实际分析还要扣除费用、检验资金机会成本，并对 `V` 做区间测试。股数减少或 EPS 提高本身不能替代上述价值检验。

将企业回购与投资者自己买卖股份分开。短期报价影响持有人的流动性和追加买入条件，长期判断仍需复核业务和资本配置。长期持有及能力圈方法不自动给出集中仓位；组合承受力使用[投资组合分析与跟踪](investment-analysis.md)。

拆股、类别转换及资本重构先按经济权利和表决权做交易前后对照：单位数量变化本身不增加企业价值；各类别的转换方向、比例、期限和限制需查当前文件。公平沟通应帮助持有人理解价值与风险，不能替代对未来股价或流动性的检验。

## 交付与复核

交付一份治理证据表、一份按期间闭合的资本来源与用途表，以及候选用途的每股价值、现金和压力情景比较。标明披露或实施权缺口，列出会改变判断的资本开支、收购条款、激励、回购价格及流动性变化。投资选择按既有项目确认责任处理，研究方法不授予公司治理干预或交易权限。

## D-002：明确约 30 分钟为非强制效率参考
- 状态：confirmed
- 提出者：用户。
- 问题与候选方案：约 30 分钟应作为强制 SLA、验收门槛，还是用于表达期望改善幅度的参考值。

- 适用范围与影响：适用于 A-001 的产品目标、MVP 流程和验收方向；不得以未达到固定 30 分钟直接判定产品失败，后续结合真实清单复杂度和基线数据衡量改善。
- 替代关系：细化 A-001 0.5 中对约 30 分钟目标的表述，不替代 D-001。
- 记录人及更新日期：`product-manager`，2026-10-06。

## D-004：确认 MVP 技术架构基线
- 状态：confirmed
- 提出者：`architect`
- 问题与候选方案：确定 MVP 的客户端形态、PDF 分析与计价职责位置、服务端长期数据边界、技术栈及生产接入方式；讨论过 Windows 与 Web 并行或仅 Windows、客户端或服务端分析 PDF、客户端或服务端计价、服务端保存或不保存生产商业务数据、C/C++ HTTP 服务器框架以及是否引入 Nginx。
- 确认人：本次建项用户。
- 结果：首期只建设 Windows 桌面客户端，使用 C++、Qt、SQLite 和本地受管文件；客户端负责交互、结构化明细人工编辑与确认、本地确定性计价、报价保存和追溯，不解析 PDF、不展示原始 PDF、不做原文位置高亮。服务端以 Linux/glibc 为运行基线，使用 C++17/20、Drogon、libcurl、PostgreSQL 和异步 Worker，临时接收 PDF，通过文本提取、必要时 OCR 和大模型生成候选结构化数据，并提供全局标准目录匹配、价格快照、版本化签名公式包、账号年度订阅与设备授权。服务端不长期保存生产商的客户、报价和本地计价参数等业务数据；当前不启用企业业务数据或多租户业务域。原材料行情采用可插拔适配器，首期支持人工维护和文件导入。目标毛利率按不含税、不含运费出厂价计算，税费和运费独立。生产环境使用 Nginx 作为 Drogon 前置入口，开发环境可以直连 Drogon。同一 Windows 客户端可依据服务端平台管理员角色显示独立管理入口，但不提供远程 Shell、任意文件访问或直接数据库操作。
- 确认来源与日期：用户于 2026-10-08 至 2026-10-09 在架构师会话中逐项确认上述边界，并在完成 Drogon 与 Nginx 讨论后于 2026-10-09 明确“OK，那就先确认这个方案了”；随后要求将本轮方案正式整理为架构候选成果和项目决定。
- 适用范围与影响：作为 T-002 和 A-002 0.1 的 MVP 架构基线，允许后续围绕该边界开展验证和开发拆分；不批准 A-002 全文，不确认尚缺失的 PDF 字段、真实公式、具体行情源、模型供应商、性能指标、保留期限、订阅价格或生产部署验收。上述细节需要真实资料、验证结果或后续决定。
- 替代关系：细化 D-001 与 D-003 在技术实现和商业授权方面的边界，不替代既有决定；基线发生实质变化时新增决定，不覆盖本记录。
- 记录人及更新日期：`architect`，2026-10-09。

## D-005：确认 Windows 桌面客户端为长期唯一客户端形态
- 状态：confirmed
- 提出者：用户。
- 问题与候选方案：D-004 中“首期只建设 Windows 桌面客户端”是 MVP 阶段安排，还是项目当前及后续长期产品边界。
- 确认人：本次建项用户。
- 结果：报价系统只提供 Windows 桌面客户端；当前及后续均不建设 Web 客户端。
- 确认来源与日期：用户于 2026-10-10 在项目经理会话中明确“只提供 Windows 桌面客户端，后期也不做 Web 客户端”。
- 适用范围与影响：适用于 PROJECT、T-001/A-001、T-002/A-002 及后续开发拆分；Windows 桌面客户端是长期唯一客户端形态，Web 客户端属于项目非目标。若未来改变该边界，必须新增决定，不得静默改成阶段性约束。
- 替代关系：细化 D-004 中“首期只建设 Windows 桌面客户端”的时间边界，不替代 D-004 的其他架构结论。
- 记录人及更新日期：`project-manager`，2026-10-10。

## D-006：确认不建设企业业务数据和多租户业务域且服务端不保存生产商客户业务数据
- 状态：confirmed
- 提出者：用户。
- 问题与候选方案：企业业务数据和多租户业务域是暂不启用但为未来预留，还是明确不建设；服务端受控接口是否意味着服务端持有可供生产商访问的其他客户业务数据。
- 确认人：本次建项用户。
- 结果：不建设企业业务数据或多租户业务域，不为此预埋无实际语义的 `organizationId`。服务端不保存生产商的客户资料、询价单、报价单和本地计价参数；生产商经受控业务接口只能取得其账号或设备已获授权的平台数据，不能修改平台目录、公式或价格源，也不能访问其他账号或设备的授权数据。
- 确认来源与日期：用户于 2026-10-10 在项目经理会话中明确该边界“不是不启用，是不做”，并指出服务端不保存客户数据，因此架构正文不应出现可访问“其他客户数据”的表述。
- 适用范围与影响：适用于 PROJECT、T-001/A-001、T-002/A-002 及后续数据模型、接口和权限设计；订阅账号、客户端设备授权及平台公共数据不属于生产商客户业务数据。A-002 需要同步修订相关约束、权衡和接口表述。
- 替代关系：细化 D-004 中“当前不启用企业业务数据或多租户业务域”及服务端业务数据边界，不替代 D-004 的其他架构结论。
- 记录人及更新日期：`project-manager`，2026-10-10。

# 价值投资尽调与催化剂

用于核实会改变个券价值或预期回报的假设。方法参考格林沃尔德等《价值投资：从格雷厄姆到巴菲特（第 2 版）》第 9、11 章。数值和条款按[证券分析](securities-analysis.md)核查，价值区间按[价值投资与企业估值](value-investing.md)计算。

## 给待验证的问题排优先级

1. 写下初步估值、市场共识所隐含的假设、自己判断不同的原因。对争议变量做敏感性测试，优先查足以改变价值区间、偿债结论或可接受价格的变量。
2. 按机会类型定问题。清算或困境证券重点查同一法律主体的抵押、债权顺序、回收额和延迟。竞争激烈的企业重点查资产再生产成本、正常盈利及存活能力。拥有护城河的公司重点查优势覆盖与持续期、分配能力和新增资本的实际回报。短期波动先检验是否影响长期现金流或危及存活。
3. 用持仓披露、内部人公开申报、同业观点和融资动作发现线索。机构持仓同时记录持有期和披露日，识别滞后。内部人交易区分公开市场自购、薪酬发放及预设交易。检查增发是为填补资金缺口还是换取足够的资产价值，列明对原股东的稀释。对每条线索保留其他合理解释。
4. 从年报、附注、公告、契约、公开会议纪要和竞争者披露提取直接证据。估计客户或渠道指标时按地区、门店类型或客户群挑选能覆盖差异的样本。访谈按授权和公开信息边界执行，先查公开纪要，再针对决定性缺口提问。记录样本偏差、证据冲突和仍需验证的反例。

## 评价管理层和资本配置

| 维度 | 对照证据 |
| --- | --- |
| 运营效率 | 以同业同口径的单位成本、周转、服务质量或研发效率比较。用跨期数据核实改善是否持续，短期削支是否伤及维护与客户。 |
| 成长策略 | 查过去的扩张或收购承诺与实际结果，按项目追踪总投入、完成时间、追加成本、税后收益及撤出残值。说明能否复用竞争优势。 |
| 财务结构与分派 | 查净回购价格、增发稀释、分红、偿债和融资安排。检验过往留存带来的现金盈利或每股价值增长，分辨市场估值变化的贡献。 |
| 人员与治理 | 查经营团队任期、梯队和继任、周期中招裁节奏、激励指标、关联交易与少数股东待遇。对新管理层以计划、授权、资源及已验证里程碑估影响。 |

历史管理效果可能已计入正常利润。单列还未反映的措施，以独立的成本、进度和收益估算其增量，按证据质量决定是否纳入基准。

## 催化剂与非公开市场价值

- 对资产出售、分拆、回购、重组、要约或经营改善，记录发起方、经济利益、投票或实施权、必要条件、费用与时间。另算延期、失败和维持现状的价值及持有回报。等待期仍可获得现金分配或有效再投资时，量化这部分回报。若持续烧钱、低效投资或新增债务会吞噬折价，检查催化剂能否赶在价值受损前兑现。
- 非公开市场价值（PMV）用行业买家对可比资产或业务实际支付的价格校验。建立交易样本表，记录交易日期、标的范围、承担债务、控制权、协同、价格及可比经营量。按统一的 EV/正常化 EBITDA 或每单位运营量估各分部，分别估独立经营及有可信买家的可实现情景。分部加总后处理总部成本、债务、其他索取权、税费和持股比例。
- 对重组或价差机会，逐情景列出回收金额和日期、合规及融资条件、展期和最坏流动性。只在可信度足够时赋予情景概率。单笔期初支出、期末收回且期间无支付时，可用 `(净回收额 ÷ 买入总成本)^(1/等待年数) − 1` 年化。多笔支付时按实际日期用 IRR 或 XIRR。回收额相同也要重算延期后的年化回报。

## 选择研究路径的历史实践

| 研究问题 | 实践启发与核查动作 |
| --- | --- |
| 好生意能否持续为股东创造价值 | **巴菲特**。用正常现金盈利和维持投入测业务经济性，检查每股价值与留存回报，比较同样的价格买入企业股权或合同现金流。对轻资本和重资本企业核对增长所需资金及稀释。 |
| 自己是否具备研究或选人优势 | **罗伯特·海尔布伦**。结合证券自身历史和同行筛选，再用监管档案与独立证据验证。评估管理人时核对专业范围、费用、资金容量和业绩是否来自同一方法。 |
| 资产折价能否存续到兑现 | **沃尔特和埃德温·施洛斯**。从新低与资产折价找线索，查表外债务、设备更新、资本消耗及修复条件。净资产法与正常盈利交叉验证，用同一行业的低杠杆和低成本企业做对照。 |
| 分部在产业买家眼里值多少 | **马里奥·加贝利**。积累成交价及运营单位数据，用分部 PMV 检验市场价格，核查可能令估值收敛的事件和交易可比性。 |
| 成熟好企业遇到的冲击是否暂时 | **格兰·格林伯格**。维护少数已跟踪的优质公司候选，先检验持久盈利和管理层，再用反证检验竞争或周期冲击。集中持有依赖持续深入研究及组合承受力。 |
| 运营改善有没有可执行方案 | **保罗·希拉勒**。以落后企业与高效同行的差距找到改善项目，核对治理权、管理人选、实施成本和董事会支持。 |
| 小型细分市场龙头的优势能否迁移 | **扬·胡梅尔**。定义地区或细分产品市场，检验当地成本和客户锁定。先做初筛，再按证据升级研究优先级，检查管理层激励、流动性和币种。 |
| 复杂困境标的的下行由谁承担 | **塞思·A. 卡拉曼**。先识别受限卖方和自己能承受的等待期，再核查偿付顺位、金额和时间，用现金与组合承受力约束持有。 |
| 长期持有与事件机会如何比较 | **迈克尔·普赖斯**。先用资产与盈利做估值，再以产业交易交叉验证，持续跟踪重组和候选。逐笔计算事件失败损失，汇总共用的融资或监管条件。 |
| 当前利润下降能否换来高回报增长 | **托马斯·鲁索**。核对品牌与渠道的可复制性、前置投入和兑现期限，追踪新市场的回报。检验家族控制是否同时支持长期投入与少数股东权益。 |
| 基金折价或不同类别证券价差能否兑现 | **安德鲁·韦斯**。穿透持仓净值、费用和索取权，分开估基础资产折价和基金份额折价。若底层价值 100、净值 80、份额对价 64，两层各折价 20%，合计折价 36%。核查净值能否实现、投票与清算权，及可能的对冲成本与期限。 |

## 交付与复盘

按 `假设 → 原始证据 → 反证 → 估值变化 → 复核触发条件` 留底，交付最影响结论的事项和未解决的不确定性。记录买入、观察、持有、退出或放弃的理由及当时可得信息。定期回看哪些预测落空、哪些程序反复被跳过，并分别归因于估值、证据、兑现时间、仓位或行为偏差。

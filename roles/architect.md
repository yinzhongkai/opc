# 系统架构师

## 职责

- 依据需求设计系统边界、模块、接口、数据模型和关键质量属性。
- 评估方案权衡与风险，为关键不确定性提出验证办法。
- 向前后端研发与测试成员提供可实现、可验证的技术契约。
- 评审需求、实现说明和测试方案，检查技术可行性、接口与数据契约的一致性以及关键质量属性的覆盖。

## 边界

- 不擅自改变产品范围和业务优先级。
- 架构方案不自动授权生产部署或破坏性数据变更。
- 不以架构视角意见代替业务决定或实际测试证据。

## 主要产出

- 架构说明、接口契约、数据模型、技术决策、风险记录和架构评审意见。

## 视觉风格基准

1. **手绘质感**：采用彩色铅笔或蜡笔般的可见笔触、轻微颗粒感和不完全均匀的填色，避免过度光滑的写实渲染。
2. **画面气质**：白色或浅色留白背景，色彩明快，人物造型简洁、表情生动，整体亲切、轻松但能有效表达情绪。
3. **竖版构图**：参考图约为 3:4 竖版，常以上下两幕形成“原先状态—后续变化”的对照；实际图片数量与分格可根据故事需要调整。
4. **文字呈现**：参考图使用中文短句和手写感英文标语。后续内容可借鉴其简短、醒目的排版，是否保留英文须在具体任务中确认；文字不得遮挡关键动作与表情。
5. **叙事对照**：可借用“被误解的特点—在合适场景中显现价值”的正向重构思路，但不要求每篇都写成职业转化，也不复制参考图的原文案、水印或账号标识。
6. **一致与可读**：同一故事中的主要人物形象、色彩和画风保持一致；缩略阅读时仍能看清关键人物、动作和文字。

## 内容类型与完整性要求

每篇可根据选题采用以下一种结构，或将幽默与哲理自然结合；不强行给每则笑话附加说教。

1. **哲理小故事**：明确人物与处境，以具体事件形成问题、困难、选择或愿望；人物通过行动推动情节，结局回应主要冲突或选择，哲理从经历和结果中自然显现，不用空泛口号代替故事。
2. **幽默笑话**：建立清楚的人物与情境，通过铺垫形成预期，再以误解、反差、意外但可理解的回应或反转形成笑点；结尾应收束包袱，而不是只有与情境无关的口号。
3. **幽默且有领悟**：笑点和领悟都来自同一事件及人物选择，二者不相互割裂，也不在笑点之后额外堆砌说教。
4. **图文互相推进**：每幅图应呈现关键场景、动作、表情或变化，避免只重复相同姿势或使用与正文无关的装饰画面。

## 后续单篇自查

- 是否能用几句话清楚复述故事或笑话的情境、铺垫和收束。
- 哲理故事是否至少有一个具体事件改变人物的认识、选择或处境，哲理是否由情节自然产生。
- 笑话是否能明确指出笑点及其与前文的呼应，是否避免强行附加哲理。
- 画面是否保持参考图的手绘、竖版和清晰对照特征，并服务于本篇情节或笑点。
- 目标读者、篇幅、图片数量下限和更新节奏分别见 [D-002](../../DECISIONS.md) 至 [D-004](../../DECISIONS.md)；英文使用要求仍需在首篇 `T-003` 分镜与样篇阶段确认。

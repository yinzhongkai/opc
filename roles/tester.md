# 测试工程师

## 职责

- 根据验收标准和风险设计测试与必要的测试代码。
- 执行测试，记录环境、版本、输入、预期和实际结果。
- 区分失败、阻塞、未验证与通过，向研发成员提交可复现缺陷。
- 评审需求、架构和实现说明，检查验收标准是否可验证、边界与异常是否覆盖、证据是否充分。

## 边界

- 测试会话与产物创建会话分开，不静默修改被测实现。
- 没有实际执行或足够证据时不报告测试通过。
- 文档可验证性评审不等于测试已经执行。

## 主要产出

- 测试计划、测试代码与用例、结果证据、测试报告、缺陷清单和文档可验证性评审意见。

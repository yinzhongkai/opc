# 可灵主体与关键帧素材

适用于视觉设计师为可灵准备角色、场景、道具、分镜静帧，以及视频制作成员整理参考视频与声音。参考[来源与覆盖](../docs/kling-ai-source.md)；身份基准与跨图检查沿用[AI 角色图片一致性](ai-character-image-consistency.md)。

## 为每份输入分配职责

| 素材职责 | 需要展示的信息 | 不应被误用的信息 |
|---|---|---|
| 角色身份 | 面部、体型、稳定标记和已确认服饰 | 不自动锁定背景或构图 |
| 场景 | 布局、尺度、行动空间、光线 | 场景里的路人不自动成为角色 |
| 道具或产品 | 结构、比例、颜色、文字和操作部位 | 不能因生成好看就改变真实结构 |
| 风格 | 材质、线条、色彩和影调 | 不自动替换目标人物身份 |
| 动作 | 动作阶段、方向、接触点与速度 | 不自动继承原视频的人物和服装 |
| 运镜 | 机位轨迹、景别变化与节奏 | 不自动继承原片内容 |
| 音色 | 单人声线特征 | 不等同于配乐、音效或完整表演 |
| 关键帧 | 指定时刻的画面状态 | 不代表中间运动已经成立 |

建立素材表：稳定 ID、职责、版本、位置、来源、允许使用范围、保持项、可变量及当前工具引用。上传顺序或素材选择变化后重新核对引用，不让旧编号指向新内容。

## 图片资产与组图

先确认角色、画风和场景规范，再生成单图、多视图或组图。角色图尽量清楚展示需要保持的部分；场景图留出行动空间；产品图能看清关键结构。为转头镜头准备相应角度，为强情绪镜头准备合适表情，但不得用未经检查的补图改写基准。

已读图片指南给出的用途：Image 4.0 可用于单图、连贯组图和高分辨率资产；图片 3.0 提供多图参考及自然语言编辑；图片 3.0 Omni 强调影视构图和系列叙事；图片 O1 提供身份参考与局部变更的方法。不同版本的组图张数、分辨率和参考额度不能混用。

组图应先定义每张图的任务与共享锚点，再检查人物、服饰、道具、光线和空间连续性。独立输出多张候选图不自动等于一组连续分镜。分镜表中的文字、格线与导演注释是规划信息，作为视频输入前根据入口整理成可用静帧或明确参考职责。

局部编辑每轮明确变更与保留项，例如只调整表情或机位；修订后复查未修改区域。保持身份与保留原图每个像素不是同一件事，仍需比较实际结果。

旧版图片指南区分角色特征、人物长相、风格转绘和通用垫图。身份、整身角色与风格参考目的不同，不能将一种模式的“相似强度”数值推广到全部新模型。该版多图参考的不同主体槽位代表不同主体；同一角色的多角度资料应按所用入口的主体创建方式整理，避免被理解成多个人物。

局部重绘先限定修改区域，再描述目标内容；扩图用于拓展画面边界和调整主体在画幅中的位置。AI 模特先确定外形、姿态和场景，生成静态形象后可衔接换装或图生视频。服饰纹理、产品形状和人物身份仍须核对，文档中的生成速度与展示效果不能当作交付保证。具体面板和参数使用前按当前版本复查。

## 主体库

主体库用于复用多角度角色、道具或场景。已读 3.0 系列指南支持以多图或短角色视频创建主体，并为角色绑定音色；3.0 图生视频可额外绑定主体增强一致性。创建方式、可组合数量和模型支持范围必须在当次入口确认。

AI 自动补视图、提取描述或绑定音色后，检查其是否忠于原资产，保留主体 ID、名称、输入版本、描述与声音的对应关系。身份或服装发生实质变化时记录新版本，不能只沿用同名主体掩盖变化。

主体库减少重复输入，不保证每帧都通过检查。动作控制页面另外强调：其主体参考用于面部信息，不等同于锁定全部服化道；面部主体绑定仅支持文档指定的朝向条件。将人脸参考与完整角色资产分别管理。

## 关键帧与参考视频

首帧、尾帧和中间帧先检查角色、衣着、比例、光线和空间能否相接，再检查动作所需时间。不同角度或场景并非不能变化，但需给出可信的转换过程；必要时改为真实切镜，不强求所有差异都经过连续变形。

使用动作视频前检查目标身体与画面范围、朝向、遮挡、主要动作和接触物是否适配。使用运镜参考时核对目标主体尺度及场景深度，不能假设原片机位可以无条件迁移到任何空间。

4.0 的全能参考与专用关键帧入口目前不能混用：前者用于组合素材信息，后者用于时间线节点。素材包应按选定入口准备，不能把所有类型一起上传后再让模型猜。

## 声音素材与交接

音色提取优先选择单人、清晰、背景干净、语速适中的片段。来源是否可用于角色声线复用应明确，不能把能下载或能上传当作使用授权。具体时长与格式按所用版本复核；已读 4.0 文档的音色创建要求为 5–30 秒，不能据此覆盖所有历史功能。

数字角色的配音轨承担说什么和说多久，表演描述承担如何表现；不要把配音轨和音色样本混为一谈。检查断句、停顿与动作，单人样片通过后再扩大场景。

交付经检查的资产清单、版本与源文件、主体/声音映射、角色规范、关键帧时间表及未解决项。实际图片、音视频、生成指令与工程文件进入项目声明且获授权的成果物工作区；OPC 保存方法及治理引用。

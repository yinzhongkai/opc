## 1. 人员结论

一期完整 MVP 需要九个研发岗位。产品经理、项目经理和系统架构师负责需求、计划与技术契约，不计入下面的实现岗位；逆向研发仅提供参考能力分析，也不承担产品实现。

| 工作包 | 研发成员 | 状态 | 核心责任 |
|---|---|---|---|
| WP-01 平台构建 | `build-engineer-windows-qt-01` | 已有 | Qt SDK、CMake、依赖 ABI、CI |
| WP-02 核心领域 | `core-systems-engineer-cpp-01` | 已有 | 规范时间、事件、事务、确定性融合 |
| WP-03 产品界面 | `ui-engineer-qt-quick-01` | 本轮新增 | UI/UX、QML 工作区、时间线交互、ViewModel |
| WP-04 媒体导出 | `multimedia-engineer-ffmpeg-01` | 已有 | 解码、PTS/VFR、同步、代理、封装导出 |
| WP-05 视频算法 | `video-algorithm-engineer-cv-01` | 本轮新增 | 镜头、运动、动作峰值与效果评估 |
| WP-06 音频 DSP | `audio-dsp-engineer-01` | 本轮新增 | 节拍/瞬态、音色触发、混音、试听与 PCM/WAV |
| WP-07 实时图形 | `graphics-engineer-qt-scenegraph-01` | 本轮新增 | Scene Graph、三类模板、屏上/离屏一致性 |
| WP-08 Worker/存储 | `core-systems-engineer-cpp-01` | 已有兼任 | 作业/IPC、JSON 项目、迁移、恢复、缓存 |
| WP-09 测试质量 | `tester-cpp-qt-01` | 已有 | 契约、集成、UI、性能和故障测试 |
| WP-10 Windows 发布 | `release-engineer-windows-01` | 本轮新增 | 部署、安装、签名流程、SBOM、干净环境验收 |

UI/UX 与 Qt Quick/QML 在 MVP 内由同一成员承担，减少设计到实现的交接成本；高密度波形、频谱、粒子和离屏渲染独立交给实时图形成员，避免 UI 成员同时背负交互、产品视觉和底层 GPU 三类风险。

## 2. 新增工作流及任务

| 工作流 | 立即任务 | 基础实现 | 集成/验收 |
|---|---|---|---|
| UI | T-024 交互架构与设计系统 | T-025 QML 工作区与 C++ bridge | T-026 时间线、作业、错误及用户路径集成 |
| 视频算法 | T-027 样本/契约/指标 | T-028 经典镜头与运动算法 | T-029 效果、性能与可选模型门禁 |
| 音频 DSP | T-030 PCM/特征/音色契约 | T-031 节拍与瞬态分析 | T-032 音色触发、混音、试听与离线输出 |
| 实时图形 | T-033 RenderRecipe 与线程契约 | T-034 时间线/波形与三类视觉模板 | T-035 屏上/离屏一致性、GPU 降级和性能 |

五个立即任务不依赖 D-003 最终确认，可以先形成契约、样本、原型和计划。涉及 OpenCV、FFT、QAudioSink、Scene Graph、vcpkg、测试框架或双进程落地的基础实现，在 D-003 未确认前不得冻结依赖和版本。

## 3. 依赖顺序

1. **契约与设计**：T-014 核心时间、T-017 媒体时间、T-020 测试策略与新增 T-024/T-027/T-030/T-033/T-036 同步形成接口和验证输入。
2. **工程骨架**：T-013 提供统一 Windows x64 目标、依赖和测试入口；Qt SDK 前置 T-012 已完成。
3. **领域实现**：T-015/T-016、T-018、T-025、T-028、T-031、T-034 按契约实现，生产者同时提交模块自测。
4. **功能闭环**：T-026 完成用户编辑路径，T-029 完成视频效果证据，T-032 生成节奏音轨，T-035 提供视觉帧，T-019 把固定修订的音频与视觉封装导出。
5. **质量与发布**：T-021 建立契约测试，T-022 验证端到端和故障，T-037/T-038 建立发布候选；任何测试、安装或签名成功均不自动批准产品发布。

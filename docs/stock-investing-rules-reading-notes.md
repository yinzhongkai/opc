## 全书归纳与方法落点

全书把研究过程连为：理解企业和行业、核查财务与管理、估计现金及优势持续期、比较价格、持续复核。最有用的增量是把“好公司”变成可调查的竞争机制，再针对行业选指标。原有估值和现金方法继续保留，避免建立相互冲突的第二套公式。

| 章节 | 独立归纳及应用 |
| --- | --- |
| 序、前言 | 独立判断，区分企业质量与股票买价；信息数据库与研究纪律重要，权威不能代替自己核查。 |
| 1 五项原则 | 研究、优势、安全边际、长期和卖出条件构成闭环。费税和频繁换手可侵蚀复利；原书税率、仓位与折价示例不是统一规则。 |
| 2 七种错误 | 避免投机故事、时代例外论、产品偏爱、恐慌、择时、忽略估值和只看盈利。历史研究与作者断言不等同于所有市场的定律。 |
| 3 竞争优势 | 先看回报，再问来源、持续期和行业；区分品牌、成本、转换、网络及进入限制。高利润和高份额均需替代解释。 |
| 4 投资语言 | 资产负债表是时点，利润和现金流是期间；赊销、折旧、采购与融资使利润和现金不同。热狗摊例子用于理解三表连接。 |
| 5 财报讲解 | Dell、HP 的历史报表说明应收、存货、商誉、一次性项目、股数与现金用途。并购和不同会计年必须调整可比性。 |
| 6 公司基础 | 拆增长来源、利润率与周转、杠杆、现金和负债；单列最强不利情景，检验客户及融资链的脆弱性。 |
| 7 管理 | 报酬要看实际激励，承诺要对照结果；查关联交易、继任、资本配置和披露。个人风格不能直接证明经营质量。 |
| 8 财务伪装 | 现金与利润背离、反复重组、并购、应收和存货、资本化、养老金等是核查线索。异常不自动证明舞弊，先查业务和会计解释。 |
| 9 相对估值 | P/S、P/B、P/E、PEG及现金收益率各有分母和局限；低倍数可能来自周期峰值或结构衰退，同行贵也不能证明便宜。 |
| 10 内在价值 | 金额、时点、风险和终值共同影响现值；披露关键假设、口径和敏感性。安全边际不能修复一个不适用的模型。 |
| 11 综合案例 | AMD 和 Biomet 是约2003年的分析，不是当期评级。前者展示资本密集和周期压力，后者展示转换成本与成长持续期；延长预测期会显著改变估值。 |
| 12 十分钟测试 | 快速检查质量、盈利、现金、杠杆、一次性项目和稀释，只用于决定是否继续研究。微型、境外、IPO 等原书筛选偏好不形成框架禁令。 |
| 13 行业指南 | 先理解各行业如何赚钱、为何竞争、现金需要多少；行业偏好具有写作时点，不能代替个券证据和价格判断。 |
| 14 医疗保健 | 分药品、生技、器械及管理医疗，区分使用者、决策者和付款者，查专利、研发、审批、报销及资金。旧成功率与审批期限只作历史材料。 |
| 15 消费者服务 | 餐饮生命周期、单店复制、成熟同店和现金周转相互联系。扩张可导致资金缺口，租赁和翻新成本须完整计入。 |
| 16 商务服务 | 技术、人力及实体资产三类的增长约束不同。外包、规模和长约可能有利，但仍查服务成本、合同质量、客户及资金。 |
| 17 银行 | 信用、流动性和利率风险要联动；查存款、拨备、资本、效率和贷款组合。高杠杆放大损失，历史收益和资本比率不能成为安全保证。 |
| 18 资管与保险 | 资管拆市场涨跌、净资金和费率；保险拆承保、投资、准备金、长尾及资本。不同经济性质不能只因“用别人的钱”归为同类。 |
| 19 软件 | 许可、维护、递延和应收帮助理解当时模式；转换与网络要有客户证据。使用时重新核对订阅、用量、收入及成本结构。 |
| 20 硬件 | 快速创新、降价、需求周期及存货共同作用。技术进步惠及消费者，不自动让股东获利；核对规模、渠道、工艺及客户关系。 |
| 21 媒体 | 广告、订阅和单次作品的收入与现金差异很大；内容库、渠道、资本更新和控制权需分开。不能把历史报纸垄断当永久优势。 |
| 22 电信 | 固定网络成本、技术替代、监管与债务共同约束回报。EBITDA 不能替代更新资本、占款和现金税后的余量。 |
| 23 生活消费品 | 量价、品牌、创新、渠道、成本及海外增长共同决定利润；促销、削广告、低效并购和高买价会侵蚀优势。 |
| 24 工业与材料 | 区分商品和增值产品；成本、资产周转、周期、养老金与杠杆决定低谷存活。争份额不等于创造价值。 |
| 25 能源 | 拆勘探开采、输送、炼制、销售与服务；商品价格、成本、储量增补和资本需求分别观察。原书油价及 OPEC 判断属于历史背景。 |
| 26 公用事业 | 发电、输电及配电的竞争和费率结构不同；许可、资本、环保和债务共同影响股东所得，高股息不自动安全。 |

## 阅读中发现的计算与版本问题

这些是本地文件的可观察不一致或模型使用风险；没有逐项确定属于作者、译者、排版还是转换环节。

1. 第5章部分应收、应付措辞和筹资表项目名称、正负号不协调。`Images/00053.jpg` 中普通股购买和发行标签与正负现金方向有疑点，不能按该标签直接建现金桥；应回到对应报告期原始报表核验。
2. 第6章 ROIC 框中部分资产/负债用词可疑。统一按同范围的税后经营利润及经营投入资本定义计算，并对齐平均资本、商誉和超额现金。
3. 第9章现金收益率例子把税后、含利息影响的现金指标与企业价值搭配，存在口径误用风险。不能把 `经营现金流−资本支出` 除以任意 EV 直接当资本回报或估值主模型。
4. 第10章的永续年金金额是预测期末终值，不能把整个终值当作第11年现金流；必须折现回估值日。把折价回归幅度与折现率相加，也没有自动考虑兑现年数，实际应按时间和现金测算回报。
5. 第11章 `Images/00065.jpg` 的 AMD 估值表，终值折现及总计栏出现与前面另一估值示例相同的残留数字；`00041.jpg` 的增长文字也与逐年序列不一致。不能复制原表作为可复算模板。
6. 第15章 `Images/00087.jpg` 中若干应收/应付标题及代入式与现金周转构成不一致。统一用相同期间的存货天数加收款天数减付款天数，采购额不可得时才说明成本代理。
7. “经营租赁都不在表内”、期权税效应、商誉、收入确认、监管资本、药品审批和税率均带历史条件。新任务查当期准则和披露，已计入的租赁负债或现金不能重复调整。
8. 行业财务阈值、折现率、终值增长率、固定折价比例、油价区间和收益数据均不是现成参数。书中公司也可能已经改变经营模式，尤须避免把历史 AMD 判断用于今天。

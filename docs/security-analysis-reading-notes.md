## 正文与各部分导读

| 顺读范围 | 可迁移的分析判断 |
| --- | --- |
| [第 1 章](https://weread.qq.com/web/reader/89c32460813aba25fg01310ek37632cd021737693cfc7149) | 分析首先把证据组织成可比较的事实，再决定能否据此判断价格或质疑会计、条款及经营政策。凯斯公司的多年平均盈利掩盖了年际波动；解释不了盈利从哪来、能否持续，就不能直接给平均值套倍数。即使估到价值区间，也应记录在价格回归前可能发生的基本面变化。 |
| [第 2 章](https://weread.qq.com/web/reader/89c32460813aba25fg01310ek1ff325f02181ff1de7742fc) | 先确认证券、价格、时点、使用者目标，再选择分析深度。区分发行人质量与证券持有人实际权利。报表记录需要经营原因支撑：例如需求复购、分散和存货周转，能说明何以稳定；单凭历史保障倍数高或上升趋势，无法证明下一轮仍会如此。 |
| [第 3 章](https://weread.qq.com/web/reader/89c32460813aba25fg01310ek8e232ec02198e296a067180) | 分开找发行条款、公司披露和行业基准。条款核对原契约、发行说明及修订；财务数据核对正式报告、附注和报告期间；行业数据核对定义、覆盖和时间。汇总数据只用于定位。若披露只在景气时持续、或年报与监管报表范围不一致，记录差异及可能改变的结论。 |
| 第 4 章 | 投资和投机的判断落在具体交易及其价格上，需要同时解释本金保护来自哪里、回报从哪来。持有期、票面收入和证券名称都不能单独回答。可赎回优先股以溢价买入时，须计算最早可赎回日的实际回收，并说明哪些回报依赖发行人不行权。 |
| [第 5 章](https://weread.qq.com/web/reader/89c32460813aba25fg01310ek02e32f0021b02e74f10ece8) | 按持有人的实际经济风险选择研究方法。偏债工具先看履约；具有转换等权利的工具另算期权相关情景；溢价很高的转债或只剩残余价值的劣后证券，还需像研究股权一样评估企业价值。经济表现类似，不改变原合同的受偿顺位。 |
| [第二部分导读：解开债券之谜](https://weread.qq.com/web/reader/89c32460813aba25fg01310eked332ca0262ed3d2c2191f2) | 霍华德·马克斯把历史原则放回现代信贷市场：收益率要和违约损失、流动性、条款和买价一起看。高收益债可纳入不同研究框架，但不能沿用稳健债的风险假设。经营波动和高杠杆会相互放大；初筛后仍须定期重查，并区分选券能力与利率环境带来的回报。 |
| [第 6 章](https://weread.qq.com/web/reader/89c32460813aba25fg01310ek341323f021e34173cb3824c) | 债券正常履约取决于企业偿付能力；抵押物更多影响违约后的损失。核对资产用途、处置折价、权利可执行性和等待时间。同一发行人的两档债券可以比较，先验证发行人，再问多付的价格能否换到实质保护。抵押顺位靠前但覆盖的资产弱，仍可能回收较差。 |
| [第 7 章](https://weread.qq.com/web/reader/89c32460813aba25fg01310ekc1632f5021fc16a5320f3dc) | 用历史低谷和有根据的压力情景看安全余量。公用事业案例中的脆弱性来自杠杆，铁路案例来自对行业稳定性的高估，部分工业案例来自盈利急速转负。相同表面覆盖率可能对应不同风险。高票息既不能替代信用底线，也不能视为精确的违约概率；多家发行人可能同时受冲击。 |
| [第 8 章](https://weread.qq.com/web/reader/89c32460813aba25fg01310ek636320102206364d3f0ffdc) | 在看收益前写清最低筛选标准，同时说明为什么适用于这类发行人。规模要拆成经营韧性、融资渠道和发行流动性三件事。历史上的行业白名单、绝对规模门槛会误筛。跨境债还需分别看偿付意愿、换汇汇出和追索路径。 |
| [第 9 章](https://weread.qq.com/web/reader/89c32460813aba25fg01310ek182326e0221182be0c5ca23) | 利息保障应同时列出分子、分母和涵盖的义务。只用剩余利润除以单档次级利息，可能让次级债看起来比优先债更安全；用同一主体的全口径固定费用判断整体偿付，另按条款分析各档回收。短期债要问钱从哪里来；长期债还需看利率变化对价格的影响。分红记录是线索，不能替代报表、现金流和负债到期表。 |
| [第 10 章：债券投资的具体标准（再续）](https://weread.qq.com/web/reader/89c32460813aba25fg01310eke3632bd0222e369853df322) | 可独立转卖的设备、可交易的证券或有替代租户的物业，才有机会在发行人停业后继续提供保障。铁路车辆比铁轨容易转售，但全行业萎缩也会压低设备价格；对比债务摊还与抵押物贬值速度。物业另核对可持续净租金、租户集中度、专用程度和可能优先于抵押债的租金义务。同集团证券作抵押时还要检验风险是否同源。 |
| [第 11 章：债券投资的具体标准（完）](https://weread.qq.com/web/reader/89c32460813aba25fg01310ek1c3321802231c383cd30bb3) | 账面资产、持续经营价值和处置所得分别估计。股权市值相对适用债务本金的比例可作为交叉核对，不能当作回收底价。若盈利保障看似充足但权益缓冲明显偏薄，回查折旧、异常收益及可比债券。计算时列明主体和顺位；附条件付息的债务即使不计入某项固定费用，也仍有应核对的本金义务。 |
| [第 12 章：铁路与公用事业债券分析中的特殊因素](https://weread.qq.com/web/reader/89c32460813aba25fg01310ek19c3222022419ca14e7eef7) | 分清经营维护、折旧、租金、子公司分红和税费的实际口径。延迟维护能暂时抬高利润，偶发分红也能抬高母公司单体利润；重算时剔除重复计入的集团内部收支。书中城市服务电力照明案例，发行材料显示保障约 4.1–4.9 倍，调整折旧和固定费用后约 1.16 倍。行业标签不足以证明稳定性，需看分部收入及监管条件。 |
| [第 13 章：债券分析中的其他特殊因素](https://weread.qq.com/web/reader/89c32460813aba25fg01310eka5b325d0225a5bfc9e0772d) | 并读合并和单体报表。子公司需先支付自身债息、税费及其他优先义务，再判断剩余现金能否上划给母公司；子公司间的现金与债务不能无条件互相抵销。核对租赁、担保及到期表，避免把已入账义务重复计入。营运资本和流动比率帮助筛查短期压力，但无法代替对可动用现金和到期本金的核查。 |
| [第 14 章：优先股理论](https://weread.qq.com/web/reader/89c32460813aba25fg01310eka5732aa0226a5771bce9dc4) | 优先股股息金额固定，并不表示每期都必须支付。美国钢铁优先股与 Inland Steel 债券的历史表现说明，停发股息的裁量和偿债信用是两件事。核对股息限制及表决权何时生效、谁能行使。票息差和少数幸存案例都不足以证明优先股的本金安全。 |
| [第 15 章：优先股投资的选择技巧](https://weread.qq.com/web/reader/89c32460813aba25fg01310ekd67323c0227d67d8ab4fb04) | 用同一主体、期间及税务口径重算保障，纳入在先义务和相关优先股分派；只用剩余收益除以某一档股息会高估保护。少量在先债务是否重要取决于实际金额、分派和条款。累积股息保留符合条件的欠付金额，却不承诺何时补发；非累积或附条件累积需另查历史欠息如何处理。 |
| [第 16 章：收益债券和担保证券](https://weread.qq.com/web/reader/89c32460813aba25fg01310ekd6432e00228d645920e3401) | 本章的收益债券指按契约以可用利润决定利息的债券。分别检查利润定义、储备金裁量、付息顺位和本金期限。担保需核对本息覆盖、上限、期限和触发条件；政府监督或持股不等于保证。多方担保的增益取决于能否在发行人出险时独立履约，同一冲击可能削弱所有担保人。 |
| [第 17 章：担保证券（续）](https://weread.qq.com/web/reader/89c32460813aba25fg01310ek34132fc02293416a75f431d) | 比较发行人独立、双方合计、担保人独立承担约定义务三种情景，避免重复计入集团内现金。租约可提供类似担保的付款来源，但要把租金、利息和本金逐期对齐；能付利息未必能还本金。抵押担保机构可能在共同下行时同时接到大量追偿。联合制药案例表明，母公司合并保障很高，也不能代替无担保子公司债的单体偿付分析。 |
| [第 18 章：保护性条款与优先证券持有人的补偿](https://weread.qq.com/web/reader/89c32460813aba25fg01310eka1d32a6022aa1d0c6e83eb4) | 从契约或章程提取违约事件、补救和加速到期的权限。加速到期让债权人主张本金，但匆忙处置可能损害持续经营价值；重组要比较清算、展期及交换证券的回收，并明确谁付出让步、谁得到对价。另核对受托人义务、独立性及持有人能否协调行动。书中表决权方案是作者的历史建议。 |
| [第 19 章：保护性条款（续）](https://weread.qq.com/web/reader/89c32460813aba25fg01310ek17e328b022b17e62166fad4) | 查新增担保、同等担保、购置融资例外、同顺位增发和分派限制。区分持续维持指标与仅在增发、分红时测试的指标；同一比率跌破后，后果可能是停分红、补充抵押、出售资产偿债或有权加速，需逐项核实。抵押物会耗尽或租约临近到期时，偿债基金或分期摊还尤其重要；按表核对实际出资和剩余本金。 |
| [第 20 章：优先股的保护性条款与维持充足的次级资本](https://weread.qq.com/web/reader/89c32460813aba25fg01310ekf7132c6022cf7177163c01c) | 无担保债也能排在优先股前面；不能只检查是否限制新抵押。优先股欠息后的表决权，取决于启动时间、董事席位和持有人能否组织行使；梅塔格案例中权利触发后，董事会实际控制并未相应变化。另看分红、回购和减资是否会抽走次级资本，区分账面重分类和现金流出。 |

## 供后续验证的工作方法

以下是从已读范围派生的 OPC 用法，案例数字为自拟。

1. **先对齐证据口径。** 研究卡记录证券代码、发行主体、担保人、币种、报价及日期、财报期末、报告主体、条款版本。每项关键输入注明出处，分别标记事实、调整和假设；信息缺失且足以改变结论时，列出待查文件。
2. **把偿付测试和受偿测试拆开。** 若可用于覆盖固定费用的同口径收益为 120，优先利息 60、次级利息 20，整体保障是 `120 / (60 + 20) = 1.5` 倍。只计算 `(120 − 60) / 20 = 3` 倍会掩盖整体余量。压力收益降到 70 时，整体保障降到 0.875 倍。接着另列现金、到期本金、再融资条件和回收顺位；保障倍数不能回答这些问题。
3. **区分价格保护和对未来的押注。** 假设证券买价 108，下一赎回日可按 100 赎回，该日前可得 2 的分派；同一口径下，按期赎回的现金总回收只有 102，成本前损益是 −6。再分别测算继续持有和信用恶化情景。适用时核对全价、应计金额、费税和分派是否确定。
4. **按主体画现金流和受偿顺序。** 假设子公司有可支配现金 100，本级到期义务 65，剩余 35 中只有 15 符合上划条件。测母公司还债时只计可得的 15；测子公司债时也不把母公司资金算作支持，除非合同提供可执行的追索权。将保证人承担的其他债务、租约和同时被追偿情景单列。
5. **让每条契约对应一个可执行的检查。** 摘要记录文件版本、条款位置、测试指标、触发时间、例外、补救期和有权行动的一方。用最新数据重算阈值余量，再分别评估限制分派、追加担保、加速到期及协商重组对可回收金额和时间的影响。
6. **分开比较可转债的信用支撑和股权敏感度。** 若每张可转成 2 股，股价 65，则即时转股价值是 130；可转债报 132，并不能据此推断它在股价下跌时也值 130。单独估计不转股时的债务现金流与违约回收，再按行权期限和赎回条件做股价情景。
7. **按受偿顺位算每档能分到多少。** 假设扣除处置费用后可分配 110，先偿高级债 80，再偿同顺位的两档次级债 20 和 40。若按本金比例分配剩下的 30，两档分别收回 10 和 20，优先股和普通股没有剩余可分。资产价值、处置时间和在先债务变化时，重算各档回收金额及现值。
8. **用相同股数口径检验分派。** 假设公司每 10 股送 1 股，送股前每股现金股息 1.10，送股后每股现金股息 1.00。按原持有 10 股计算，两期实收都是 11。若公告同时宣称提高现金回报，核对调整后的每股金额、公司现金流和派息覆盖。
9. **识别折旧变化对报告盈利的影响。** 假设期初资产账面额从 100 减记为 60，剩余寿命 5 年，残值为零。直线折旧由每年 20 降到 12。其余条件相同时，后续税前报告利润每年增加 8。核对减记后的实际产能和维持性资本开支，再确定分析口径。

# 核心系统工程师

## 职责

- 依据已确认架构契约实现时间、事件、状态事务、进程协作和持久化等基础系统能力。
- 定义并维护核心模块的不变量、接口行为、数据所有权、并发边界、错误处理和兼容演进机制。
- 为确定性、可恢复性、性能和故障隔离建立自动化测试与可复现的诊断证据。
- 向界面、算法、构建和测试成员提供稳定的核心接口与集成说明，评审涉及基础数据和运行时边界的实现变更。

## 边界

- 不擅自改变产品范围、架构关键决策或用户尚未确认的技术选型。
- 不把核心实现细节泄露成所有上层模块必须依赖的接口；跨进程、存储和公共数据契约的破坏性变化须进入相应决策与迁移流程。
- 不代替专项算法、界面、构建或测试岗位作出其专业结论，生产发布须有相应授权。

## 主要产出

- 核心 C/C++ 模块、接口与数据契约、单元和集成测试、迁移与恢复机制、性能及故障诊断资料和开发交接说明。

# 多元模型与逆向推理

用于研究一个结果由哪些机制产生、哪些条件会令判断失效。主要根据《穷查理宝典》第二章及第四章第2–5、9–10讲整理；[阅读范围与来源](../docs/poor-charlies-almanack-reading-notes.md)保留一处网页显示缺口。本文是可复用的方法归纳，书中轶事、作者分类及类比各有证据边界。

## 先限定问题与能力边界

写明研究对象、待解释的结果、分析截止日、可选行动、时间跨度和约束。将关键未知分为能补证、能作有依据的情景、暂时无法合理估计三类。能复述行业术语或专家结论，不等于能解释关键输入、反例和失效条件；对超出能力的部分保留未知，并说明是否影响下一步判断。

先用简单关系解释结果。例如把收入拆成数量、价格和组合，把现金拆成经营流入、必要投入及融资义务。核对单位、分母、时间及主体；复杂模型应回答简单关系尚未解决的问题。

## 为机制选择模型

按问题选少量相关模型，不要求每份研究凑齐学科或套用固定数量。重要的定性因素仍需列出，并注明尚不能量化的原因。

| 视角 | 具体问题 | 核验及限制 |
| --- | --- | --- |
| 概率与基准率 | 类似情形通常怎样？新证据改变了什么？ | 说明参照组、样本、选择偏差和条件变化；没有依据时不用精确概率装饰判断 |
| 复利与资本约束 | 什么能持续再投入，多久，靠谁出资？ | 使用税费后的现金、增量回报、容量和持续期限；固定增长是情景假设 |
| 机会成本 | 同一资源还有什么可行用途？ | 比较相同期限、风险、费用及约束下的替代项，包括维持现状或继续研究 |
| 激励与行为 | 谁得到奖励、掌握信息、承担长期损失？ | 将薪酬、合同及实际行为对应；利益冲突是核查线索，不独立证明不诚实 |
| 规模、竞争与生态 | 优势通过什么渠道产生，谁会反应？ | 核对成本、分销、客户留存、替代、进入和组织成本；规模也会增加协调负担 |
| 反馈、阈值与延迟 | 结果会反过来改变输入吗？何时突然失效？ | 写出因果方向、时间和阈值依据；警惕把历史平稳误当作没有尾部风险 |
| 冗余与安全余量 | 单点失败能否导致不可恢复的损失？ | 检查缓冲的可用时点、共同失效和代价；工程类比不直接给出金融概率 |

数学、工程、心理及生物学可以提供问题和机制线索，跨领域应用时仍需验证对象是否具备相同结构。自然规律、实验结论、商业经验和修辞类比分别标明；不能因名称相似便把原领域的确定性一同移入。

## 同时做正向推导与失败推演

1. 正向列出成功所需的因果链：需求如何转成收入，收入如何转成持有人可得现金，兑现前需要哪些投入与许可。
2. 反向假设关键判断失败，列出可能原因：需求消失、竞争降价、成本上升、估计错误、融资中断、期限错配、执行受阻或治理失效。
3. 对每条重要失败路径写出最早可观察的证据、现有防线、剩余损失和缺口。优先处理后果不可恢复且证据薄弱的路径，不能只按发生频率排序。
4. 检查防线是否共用同一资金、供应商、模型或批准条件。两项缓冲受同一冲击失效时，不把数量当作独立保护。
5. 将结果与替代解释比较，写明最有力的反对论证及改变结论的证据。保留原判断的时间和版本。

失败推演用于发现遗漏，不能替代实际发生概率、现金预算或具体合同核验。证券偿付及流动性计算使用[证券分析](securities-analysis.md)、[投资资产与合约风险分析](asset-and-contract-risk-analysis.md)和[投资组合分析](investment-analysis.md)。

## 检查相互作用与二阶后果

画出或用文字列出“原因 → 行为 → 结果 → 对输入的反作用”，区分增强、抵消、依赖和延迟。每条关键连接都附证据或标为待验证假设。多个有利因素同时存在不证明它们相互增强；多个模型得出相同结论，也可能只是重复用了同一个收入预测。

考虑竞争者、客户、雇员和资金提供者会如何响应。技术降低单位成本后，收益可能被价格竞争转给客户；销售奖励提高销量，也可能改变订单质量、退货和现金回收。比较初始效果、后续反应与净效果。

自拟研究例：一家设备企业宣传客户扩产、订单增长、规模降本和高资本回报。先核实订单能否取消、客户融资及验收回款，再检查同行扩产是否压低价格。若客户融资收紧同时减少交付、延迟回款并增加库存，三项损失属于一条共同压力链，需联动计算，不能在不同情景里分开淡化。成本下降能否保留，还取决于客户议价及替代供给。该例不涉及任何实际公司判断。

## 交付与学习

在原有研究底稿中加入必要信息即可，不另建重复台账：

- 问题、时间和能力边界；关键事实、未知与替代项。
- 主导机制、采用模型、证据、失效条件，以及模型间是否共用输入。
- 成功链与失败链、二阶反应、共同失效及对现金和价值的影响。
- 当前结论、最强反证、待补资料和触发复核的变化。

复盘时比较当时预测与实际，区分输入变化、机制错误、行为偏差和运气。对重要但少用的判断方法用案例演练与回顾保持熟练；学习以能解释、应用和修正为依据，不按阅读量或术语数量计分。

配合[判断偏差与决策检查](decision-bias-checklist.md)检查研究者自己的激励、承诺和信息选择。资本配置与估值主模型继续使用既有技能。方法不改变任务、评审、授权或批准流程。

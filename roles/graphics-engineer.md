# 实时图形工程师

## 职责

- 设计并实现高密度、实时和离屏图形渲染模块，维护渲染数据、资源和线程边界。
- 建立可版本化的渲染配方、模板、GPU 能力探测、降级路径和屏上/离屏一致性。
- 对几何批处理、着色器、资源生命周期、帧时序和 GPU/CPU 性能进行测量与优化。
- 向界面、媒体、音频、构建和测试成员提供稳定渲染接口与验证资料。

## 边界

- 不擅自改变产品交互流程、核心事件语义、音频分析或媒体编码规则。
- 不将图形后端私有对象暴露为业务公共契约，不以单一 GPU 结果代替兼容性结论。
- 不负责安装器、签名或生产发布批准。

## 主要产出

- 实时与离屏渲染模块、渲染配方和模板、性能与兼容性测试、GPU 降级方案及开发交接资料。

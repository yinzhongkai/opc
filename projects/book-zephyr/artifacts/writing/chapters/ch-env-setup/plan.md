## 学习目标与前提

本章结束并完成实验后，读者应能：

1. 说出 nRF54L15 SoC 的主要组成（Cortex-M33 应用核 + FLPR RISC-V 协处理器、1.5 MB RRAM、256 KB RAM、电源域概念、主要外设清单），并在 DK 实物上指出主芯片、天线、按键/LED、USB 口、电流测量头的位置；
2. 在 Windows 主机上从零安装 nRF Connect 开发环境（nRF Connect for Desktop → Toolchain Manager → NCS v3.4.0 工具链与 SDK → VS Code 与 nRF Connect 扩展），并用命令行验证工具链可用；
3. 基于官方示例创建工程，完成"构建 → 烧录 → 上板观察"的完整循环（blinky：LED 闪烁）；
4. 修改示例参数（闪烁周期）后重新构建烧录，确认自己掌控该循环；
5. 说出官方资料（数据手册、DK 用户指南、Rev 2 勘误表、NCS 在线文档、DevZone）各自的用途，并能按板卡版本找到对应勘误。

**已具备的知识**：读者画像按 D-001（熟练 C 与系统编程、熟悉驱动与体系结构概念，无 MCU/RTOS/BLE 经验）；前置章节为导读 ch-intro（物料清单、反馈方式）。

**所需资源**：Windows 主机（D-005 确认当前未装任何开发软件，本章从零写起）；nRF54L15 DK 1.0.0（Rev 2 芯片，实物已与资料包核对一致）；USB-C 数据线；可访问 nordicsemi.com 的网络。

**待核实假设**（蓝图级标注，正文写作前由 environment.md 基线确认落实）：

- NCS v3.4.0 在 Windows 的安装流程细节（Toolchain Manager 版本、下载体积与耗时、路径要求）——目前为官方资料核查级，未实机执行；
- DK 出厂板载调试器固件是否提示升级以匹配 v3.4.0——待用户实机照做时验证；
- blinky 示例对 `nrf54l15dk/nrf54l15/cpuapp` 板级目标的支持——Zephyr 官方板级文档列明 LED 支持（资料核查级），实机运行结果为"未执行"。

## 易错点与交付条件

**易错点**（均为教学提示，来源：Nordic 官方安装文档、DK 用户指南与社区常见问题——资料核查级，不冒充亲历）：

- Windows 安装路径避免空格与中文字符，安装需足够磁盘空间与网络稳定（下载体积大）；
- USB 线必须是数据线（仅充电线是最常见的"连不上"原因）；
- 板载调试器可能提示固件升级，按 nRF Connect for Desktop 提示操作；
- 板级目标勿写错：本章统一使用 `nrf54l15dk/nrf54l15/cpuapp`；
- DK 的 VDD 默认 1.8 V，本章不涉及外接模块，无需调整（Board Configurator 在第 7 章前用不到）。

**试读前需解决的主线阻断项**：

- environment.md 环境基线尚未确认（属 developer 职责，待立项登记）；本蓝图按 D-005 候选基线 NCS v3.4.0 起草，基线变化时本章安装步骤与截图需同步复核；
- 安装步骤截图为占位，需用户实机照做时采集真实截图替换。

# 项目公共指令

这是所提供框架资料的入口，文件内容、来源路径和版本应保持对应。先读取根 [AGENTS.md](../../AGENTS.md)，再按请求使用相应协议：

- [SUPER_ADMIN.md](../../SUPER_ADMIN.md)：超级管理员的建项和配置工作。
- [SESSION_PROTOCOL.md](../../SESSION_PROTOCOL.md)：成员身份解析、知识加载、项目资料分层读取与刷新。
- [PROJECT_PROTOCOL.md](../../PROJECT_PROTOCOL.md)：任务、评审、交接及成果流程。
- [CONFIG_SCHEMA.md](../../CONFIG_SCHEMA.md)：需要核对的配置结构。

用户追加实际启动消息，例如“你是超级管理员”或管理员提供的成员声明。通用身份、知识和工作流规则以根协议为准，不要求无条件加载全部历史资料。

用户按项目运行协议保证当前仓库每次只有一个会话执行，并保持受评版本可读取且不变，直到本轮全部评审意见提交。这里不提供自动调度、同步或会话锁。

资料访问方式见 [README.md](README.md)。所需资料缺失或版本无法核对时如实说明；无法写回时提供目标路径和建议内容，明确尚未保存，不将副本变动视为仓库已同步。
